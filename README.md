# 📱 Siljang.ai - 1인 고관여 서비스직 전용 글로벌 AI 예약·상담 플랫폼

> **1인 고관여 서비스직 전용 글로벌 AI 예약·상담 플랫폼 — 인스타 네이티브 & 법조문 RRF RAG**

실시간 고객 응대가 물리적으로 불가능한 1인 점주/프리랜서(브로우샵, 반영구/타투샵, 1인 필라테스, 꽃집, 네일샵, 1인 에스테틱, 야외/웨딩 스냅 작가, 퍼스널 스타일리스트 등)를 위한 독립 플랫폼입니다. 객단가 5만\~50만 원의 고관여 버티컬 서비스에서, 인스타그램 피드/스토리로 모객한 뒤 DM·카톡으로 필수가 되는 사전 상담(일정·견적·도안/컨셉·주의사항)을 AI가 24시간 대신합니다.

---

## 1. 해결하는 문제 — 3대 파편화 페인포인트

1. **상담의 부재와 심야 이탈 (Midnight Churn)** — 고객 탐색·문의의 골든타임은 밤 23시\~24시(침대 속 탐색). 점주 취침/퇴근으로 즉시 응대가 불가능하고, 10\~20분 내 무응답 시 고객은 경쟁 샵으로 즉시 이탈합니다.
2. **후기/포트폴리오의 분산** — 시술 사진과 후기가 네이버 블로그, 인스타그램, 카톡 후기 캡처 등으로 분산되어 고객이 일일이 찾아봐야 하는 피로도가 존재합니다.
3. **예약 및 결제 연동의 단절** — 카톡 상담 후 계좌이체 예약금 입금 확인, 노쇼 규정 안내, 네이버 캘린더 수기 등록 등 5단계 이상의 수작업이 반복됩니다.

## 2. 핵심 3요소 (The 3 Pillars)

```
[ 통합 플랫폼 (Web/App) ]
  ├── 1. 예약 (Calendar Engine)
  │       실시간 빈자리 동기화 + 노쇼 방지 예약금 에스크로/환불 규정 자동화
  ├── 2. 후기 (Verified Portfolio)
  │       실제 예약·시술 완료 고객의 포토 후기 및 시술 데이터 축적
  └── 3. AI 상담 (Midnight Concierge)
          24시간 법조문형 규정 기반 견적 산출, 주의사항 안내, 예약 유도
```

### 카톡 의존 탈피(독립 플랫폼)의 타당성

- **카카오톡 한계:** 메시지 과금(알림톡/친구톡), 커스텀 UI/캘린더 뷰 제약, 노쇼 예약금 에스크로 결제 흐름의 폐쇄성.
- **독립 플랫폼 강점:** 인스타 프로필/네이버 플레이스에 링크(PWA 웹) 한 줄만 걸어두면
  **[포트폴리오 탐색 → AI 심야 상담/견적 → 실시간 캘린더 예약 → 예약금 결제]** 가 논스톱으로 연결됩니다.
  점주 락인(Lock-in)과 수수료/구독 BM 창출이 가능합니다.

## 3. 대화 엔진 아키텍처 — "법조문형 규정(Statutory Rulebook) + RRF 하이브리드 검색"

### 1) 법조문형 규정 정의 (요건-효과 매핑)

매장 운영 정책을 법조문(조-항-호) 형태로 정형화합니다.

- **제1조 (예약금 및 환불):** 예약금 3만 원, 24시간 전 취소 100% 환불, 12시간 전 50%, 당일/15분 이상 지각 시 몰수.
- **제2조 (시술 제한 및 금기사항):** 켈로이드성 피부, 임신 초기, 아스피린 복용자는 시술 불가.
- **제3조 (리터치 요건):** 시술 후 60일 이내 1회 무료, 기간 경과 시 주당 1만 원 추가.

**효과:** LLM 환각(Hallucination) 방지, 고객 응대 시 *"매장 규정 제2조에 따라\~"* 형태의 높은 설명 가능성(Explainability), 블랙컨슈머 분쟁 사전 차단.

### 2) RRF(Reciprocal Rank Fusion) 하이브리드 검색 파이프라인

```
            고객 자연어 질의
                  │
        ┌─────────┴─────────┐
        ▼                   ▼
  Sparse Retrieval     Dense Retrieval
  (BM25 키워드)        (Vector Embedding)
        │                   │
        └─────────┬─────────┘
                  ▼
          RRF 랭킹 융합 (k=60)
                  │
                  ▼
      법조문 최적 조항 1~2개 주입 → LLM 응답
```

- **Sparse Retrieval (BM25):** "켈로이드", "리터치", "당일 취소", "노쇼" 등 고유명사·법적 키워드 완전 일치 검색.
- **Dense Retrieval (Vector Embedding):** "내일 아침에 바로 갈 수 있나요?", "흉터가 잘 남는 편이에요" 등 고객의 자연어 맥락·의미 검색.
- **RRF 랭킹 융합:**

$$RRF\_Score(d) = \sum_{m \in \{dense, sparse\}} \frac{1}{k + rank_m(d)} \quad (k=60)$$

- **장점:** 문서량이 작아도 키워드 정밀 타격과 자연어 의도 파악을 동시에 만족해, 프롬프트 컨텍스트에 최적의 1\~2개 조항만 정밀 주입. 응답 속도 극대화 및 토큰 낭비 방지.

## 4. 인스타그램 네이티브 바이오퍼널 (Bio Link Funnel)

스냅 작가, 타투이스트, 플로리스트 등은 카톡보다 **인스타 DM이 본진**입니다.

```
[인스타 피드 탐색] → [바이오 링크 탭]
      → [포트폴리오 갤러리]
      → [24시간 실시간 견적/상담] ← 법조문 RRF 대화 엔진
      → [캘린더 예약]
      → [예약금 결제] ← 노쇼 방지 에스크로
```

- 전용 링크 형태: `platform.me/shop-name`
- 바이오 링크 한 줄로 심야 컨시어지 + 예약 전환이 원스톱 해결됩니다.

## 5. 비즈니스 모델 — 외주 에이전시에서 '글로벌 버티컬 AX SaaS'로

### 크몽식 건별 외주 vs 템플릿 기반 플랫폼 (Shopify/Square 모델)

| 구분 | 외주 에이전시 (한계) | 템플릿 기반 SaaS (해결) |
| --- | --- | --- |
| 성장 구조 | 점주 1명당 세팅 인건비 발생, 선형 성장 한계 | 노코드(No-Code) 버티컬 빌더 |
| 온보딩 | 개별 개발·수작업 | 가입 후 5분 만에 [내 업종 선택 → 법조문식 룰셋 템플릿 체크 → 인스타/캘린더 연동] |
| 결과물 | 건별 납품 | 전용 AI 상담/예약 링크 (`platform.me/shop-name`) 즉시 발급 |

### 글로벌 SaaS 로드맵 (US, 일본)

- **🇯🇵 일본:** LINE + 인스타 DM 문화. 예약 문화와 노쇼(No-Show) 위약금 규정에 극도로 엄격하여 **'법조문 룰셋 + 사전 예약금' 수요가 폭발적**입니다.
- **🇺🇸 미국/글로벌:** Calendly(예약) + ManyChat(단순 버튼식 DM봇) + Stripe 결제의 파편화 상태. 법조문 RRF 기반의 똑똑한 견적 산출 및 심야 컨시어지가 부재하므로 **'서비스직 전용 AI 쇼피파이'** 로 포지셔닝합니다.
