Siljang API 계약

수제케이크 주문제작 AI 상담·예약 서비스의 화면과 카카오 챗봇이 서버와 주고받는 약속입니다. 작업마다 돌려줄 수 있는 응답을 모두 적고, 응답마다 예시를 붙였습니다.

  • 묶음(로그인·가게·주문 …)을 누르면 작업이 펼쳐집니다. 작업 이름 앞의 API-001이 계약 번호입니다.
  • 작업을 열면 아래쪽 Responses 표에 상태 번호(200·401·404·409·422 …)마다 뜻과 예시가 있습니다. 예시가 여럿이면 Examples 상자에서 고릅니다.
  • 설명 끝의 돌려주지 않는 응답은 응답 표 가운데 그 작업에 없는 상태와 그 까닭입니다.
  • 서버가 아직 없어 'Try it out'은 껐습니다. 예시의 가게 '달빛케이크'와 모든 값은 지어낸 것입니다.

원본은 siljang.ai 저장소의 api/openapi.yaml입니다. 이 페이지는 원본을 그대로 보여 주고, 작업 이름 앞의 API ID와 설명 끝의 '돌려주지 않는 응답'만 원본의 x-corthex에서 옮겨 붙였습니다.
