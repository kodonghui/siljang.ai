# SCR-030 제작 목록

- 경로: `/owner/production`
- 접근 권한: 사장님
- 상위 화면: SCR-014 사장님 로그인
- 화면 레이아웃: 사장님 화면(1280 왼쪽 메뉴, 360 위쪽 막대와 메뉴 버튼)
- 플로우: FL-008, FL-010
- 관련 SPEC: SPEC-050, SPEC-051, SPEC-053, SPEC-060
- API: API-051, API-052, API-053, API-007
- 와이어프레임: `wireframes.html#SCR-030`(상태 8개, 360·1280)
- 목업: [`SCR-030-360`](../../research/cake-mockup-2026-11/canvas/project/SCR-030-360.dc.html)(normal·empty·error), [`SCR-030-1280`](../../research/cake-mockup-2026-11/canvas/project/SCR-030-1280.dc.html)(normal). 캔버스의 '사장님 화면' 페이지([09단계 README](../09-mockup/README.md) 2절)

목적: 사장님이 날짜별로 만들 확정 주문과 재제작 주문을 픽업 시각 순으로 보고 맞춤 재료 주문·제작 시작·완성(완성 사진)을 표시합니다. 잘못 누른 표시는 5분 이내에 실행 취소합니다. (FL-008, FL-010)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 그날 주문: 주문번호·상태·픽업 시각·퀵·재제작 여부·요약(현재 버전의 크기·맛·디자인 옵션·도안·더하는 옵션·문구·색·디자인 설명·참고 사진 수, 변경됨 표시) | API-051 items |
| 알레르기 답·빼야 할 재료(없으면 '없음'). 알레르기 정보에 동의하지 않은 주문은 '알레르기: 동의 안 함(빼야 할 재료만 받음)' | API-051 items.summary(REQ-177, 설계 재검토 H6, allergyConsent는 REQ-203) |
| 제작 표시: 맞춤 재료 필요 여부·맞춤 재료 주문·제작 시작·완성 시각과 완성 사진 | API-051 items.production |
| 완성 사진 올리기 결과(장당 20MB, 5장까지) | API-007 completion_photo |

## 액션

| 액션 | 결과 | 실패 |
| --- | --- | --- |
| 날짜 고르기(어제·오늘·내일·캘린더) | 그날 목록을 다시 불러옴 | 날짜 형식이 틀리면(422) SCR-030#error에서 오늘로 돌아감 |
| 맞춤 재료 주문·제작 시작 | 그 시각을 남김: '제작 시작을 남겼어요'와 5분 동안 '실행 취소'. 이 시각은 환불 계산의 근거 | 취소된 주문(409 invalid_state)·본 뒤 바뀜은 SCR-030#stale, 이미 남긴 표시(200 unchanged)는 SCR-030#done |
| 완성(사진 5장까지) | 사진을 올리고 완성을 남김. 완성 사진 보내기를 켠 가게면 픽업 전에 손님에게 한 번: '완성을 남기고 사진을 손님에게 보냈어요'. 그 안내에서 사진마다 게시 동의를 물음(SCR-011#photo-consent) | 사진이 20MB를 넘음(413)·사진이 아님(422)·저장소 장애(503)는 SCR-030#error의 사진 필드 옆 |
| 실행 취소(5분 이내) | '실행 취소했어요'와 표시 전 버튼. 실행 취소한 기록은 남음 | 5분이 지남(409 undo_window_passed)은 SCR-030#stale |

| SCR-030#submitting | 누른 버튼이 '처리하고 있어요'로 바뀌고 이 화면의 다른 액션과 함께 막힘. 첫 요청을 아직 처리하는 중이면(409 request_in_progress) 1초 뒤 같은 요청 키로 다시 보내고, 결과는 한 번만 보임 | API-052#409:request_in_progress, API-053#409:request_in_progress |

## 케이스 유형

| 케이스 유형 | 화면에 보이는 것 |
| --- | --- |
| 접근 | 그 가게 주문만(SPEC-068). 401은 SCR-030#permission |
| 입력 | 날짜 형식·사진 형식이 틀리면 SCR-030#error |
| 대상 | 없는 주문은 SCR-030#error, 가게가 없으면 SCR-030#permission |
| 상태 변화 | 한 번 남긴 시각은 고치지 않고 5분 이내에만 실행 취소(SPEC-051). 취소된 주문은 누를 수 없음(SCR-030#stale) |
| 반복 | 같은 표시를 두 번 눌러도 한 번(SCR-030#done의 unchanged) |
| 동시 변경 | 손님 취소와 동시에 일어나면 SCR-030#stale에서 목록을 다시 읽음 |
| 외부 서비스 | 완성 사진 안내가 못 가면 다음 대화 때(SPEC-066) |
| 한도 | 완성 사진 5장, 장당 20MB(SCR-030#error) |
| 데이터 노출 | 제작 목록에는 주문 요약과 알레르기 답·빼야 할 재료만(그 주문의 행에만, 할 일 요약·알림·장부에는 넣지 않음, REQ-236). 손님 연락처는 주문 상세에서 |
| 빈 응답·끊긴 응답 | 그날 만들 주문이 없으면 SCR-030#empty. 알레르기 답이 '없음'이면 '없음', 빼야 할 재료가 비면 '없음'으로 보임(빈 곳으로 두지 않음). 알레르기 정보에 동의하지 않아 답이 없는 주문은 '없음'이 아니라 '동의 안 함(빼야 할 재료만 받음)'(REQ-203) |
| 화면 상태 | 상태마다 360·1280 와이어프레임(`wireframes.html#SCR-030`) |
