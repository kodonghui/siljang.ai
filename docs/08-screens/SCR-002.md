# SCR-002 가게 개인정보 처리방침

- 경로: `/s/:slug/privacy`
- 접근 권한: 비로그인
- 상위 화면: SCR-001 예약 링크 페이지
- 화면 레이아웃: 손님 웹 페이지(360 한 열, 1280 가운데 열)
- 플로우: FL-001, FL-003
- 관련 SPEC: SPEC-010, SPEC-011, SPEC-018
- API: API-039
- 와이어프레임: `wireframes.html#SCR-002`(상태 4개, 360·1280)
- 목업: [`SCR-002-360`](../../research/cake-mockup-2026-11/canvas/project/SCR-002-360.dc.html)(normal·error), [`SCR-002-1280`](../../research/cake-mockup-2026-11/canvas/project/SCR-002-1280.dc.html)(normal). 캔버스의 '손님 화면' 페이지([09단계 README](../09-mockup/README.md) 2절)

목적: 손님이 예약 링크 페이지와 AI 상담 고지의 링크로 그 가게의 개인정보 처리방침(국외 이전 다섯 항목 포함)을 읽습니다. (FL-001, FL-003)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 가게 이름, 처리방침 버전·게시 시각 | API-039 shopName·version·publishedAt |
| 처리방침 본문 | API-039 body |
| 국외 이전 항목: 옮기는 개인정보, 나라·시기·방법, 받는 자, 받는 자의 목적·보유 기간, 거부 방법·절차와 그 결과 | API-039 overseasTransfers |

## 액션

| 액션 | 결과 | 실패 |
| --- | --- | --- |
| 예약 링크 페이지로 | SCR-001이 열림 | 그 화면의 상태 |
| 목차의 항목 | 그 항목으로 스크롤 | 해당 없음(화면 안에서만 움직임) |

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이 상태로 오는 응답 |
| --- | --- | --- |
| SCR-002#normal | 위에 가게 이름·'버전 n · YYYY-MM-DD 게시', 목차, 본문, 국외 이전 표(360에서는 받는 자마다 카드) | API-039#200:policy |
| SCR-002#loading | 레이아웃은 그대로 두고 데이터 자리에 회색 막대를 보임. 액션 버튼은 누를 수 없음. 본문 자리는 문단 크기의 막대 | (데이터를 불러오는 동안) |
| SCR-002#error | 없는 링크나 발급 전 가게(404): '찾을 수 없어요'와 '가게 주소를 다시 확인해 주세요'. 그 밖의 실패: '문제가 생겼어요. 다시 시도해 주세요'와 다시 시도 버튼, 추적 ID | API-039#404:not_found, API-039#default:internal |
| SCR-002#rate-limited | 1분에 60번을 넘게 엶(429): '잠시 뒤 다시 시도해 주세요'와 남은 초가 지나면 다시 불러옴 | API-039#429:rate_limited |
| empty (해당 없음) | 처리방침은 다섯 항목이 모두 있을 때만 예약 링크와 함께 만들어짐(SPEC-010). 빈 처리방침은 없음 |  |
| permission (해당 없음) | 누구나 읽는 공개 페이지(로그인 없음) |  |
| stale (해당 없음) | 읽기만 하고 바꾸는 액션이 없음. 새 버전이 나오면 다시 열 때 보이고, 위에 버전과 게시 시각을 보임 |  |

## 응답과 상태

06단계 계약(`api/openapi.yaml`)의 응답마다 화면 상태 하나입니다. 오류의 문구는 06단계 오류 코드 표의 '화면에 보이는 말'입니다.

| 응답 | 화면 상태 | 화면에 보이는 것 |
| --- | --- | --- |
| API-039#200:policy | SCR-002#normal | 처리방침 본문과 국외 이전 항목 |
| API-039#404:not_found | SCR-002#error | 찾을 수 없어요 · 가게 주소를 다시 확인해 주세요(목록 링크 없음) |
| API-039#429:rate_limited | SCR-002#rate-limited | '잠시 뒤 다시 시도해 주세요' |
| API-039#default:internal | SCR-002#error | '문제가 생겼어요. 다시 시도해 주세요' |

## 케이스 유형

| 케이스 유형 | 화면에 보이는 것 |
| --- | --- |
| 대상 | 없는 링크나 발급 전 가게는 SCR-002#error의 '찾을 수 없어요' |
