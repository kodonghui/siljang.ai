# SCR-049 운영자 알림

- 경로: `/operator/alerts`
- 접근 권한: 운영자
- 상위 화면: SCR-046 운영자 로그인
- 화면 레이아웃: 운영자 화면(1280 왼쪽 메뉴, 360 위쪽 막대와 메뉴 버튼)
- 플로우: 플로우 노드 없음(06단계 API-015에서 나온 화면이고, 03단계 플로우에 운영자 알림 노드가 없음)
- 관련 SPEC: SPEC-008, SPEC-010, SPEC-017
- API: API-015
- 와이어프레임: `wireframes.html#SCR-049`(상태 6개, 360·1280)

목적: 운영자가 서버가 남긴 알림(다른 가게에 이미 연결된 채널, 개인정보 처리방침의 국외 이전 항목 누락, 한 가게의 AI 실패 반복)을 가게·건수·시각으로 봅니다. (플로우 노드 없음: 06단계 API-015에서 나온 화면이고, 03단계 플로우에 운영자 알림 노드가 없음)

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이 상태로 오는 응답 |
| --- | --- | --- |
| SCR-049#normal | 최근 순 알림 목록: 종류('다른 가게에 이미 연결된 채널'·'처리방침 국외 이전 항목 누락'·'AI 실패 반복(5분에 5번)')·가게 이름·건수·시각. 손님·주문 내용은 없고 건수만(05단계 E10). 1280: 표, 360: 알림마다 카드 | API-015#200:alerts |
| SCR-049#loading | 레이아웃은 그대로 두고 데이터 자리에 회색 막대를 보임. 액션 버튼은 누를 수 없음 | (데이터를 불러오는 동안) |
| SCR-049#empty | 알림이 없음(empty): '운영자 알림이 없어요' | API-015#200:empty |
| SCR-049#error | 주소의 필터·페이지 값이 틀림(422 validation_failed): '입력한 내용을 확인해 주세요'와 '처음부터 보기'. 그 밖의 실패: '문제가 생겼어요. 다시 시도해 주세요'와 다시 시도 버튼, 추적 ID | API-015#422:validation_failed, API-015#default:internal |
| SCR-049#permission | 운영자 로그인이 없거나 만료됐거나 운영자 계정이 아님(401 unauthenticated): 운영자 로그인(SCR-046)으로 이동하고, 로그인하면 이 화면으로 돌아옴('다시 로그인해 주세요'). 이동하기 전에도 운영자 기록은 하나도 보이지 않음(G1, 06단계 DEC-11) | API-015#401:unauthenticated |
| SCR-049#stale | 목록은 연 시각 기준이라 그 뒤 바뀐 것이 안 보일 수 있음: 맨 위에 'HH:MM 기준'과 '새로 고침'. 다른 화면에서 처리하고 돌아오면 다시 불러옴 | - |

## 응답과 상태

06단계 계약(`api/openapi.yaml`)의 응답마다 화면 상태 하나입니다. 오류의 문구는 06단계 오류 코드 표의 '화면에 보이는 말'입니다.

| 응답 | 화면 상태 | 화면에 보이는 것 |
| --- | --- | --- |
| API-015#200:alerts | SCR-049#normal | 알림 목록(종류·가게·건수·시각, 내용 없음) |
| API-015#200:empty | SCR-049#empty | '운영자 알림이 없어요' |
| API-015#401:unauthenticated | SCR-049#permission | '다시 로그인해 주세요' |
| API-015#422:validation_failed | SCR-049#error | '입력한 내용을 확인해 주세요' |
| API-015#default:internal | SCR-049#error | '문제가 생겼어요. 다시 시도해 주세요' |

## 케이스 유형

| 케이스 유형 | 화면에 보이는 것 |
| --- | --- |
| 접근 | 운영자 계정만. 401은 SCR-049#permission(운영자 기록은 보이지 않음) |
| 입력 | 주소의 페이지 값이 틀리면 SCR-049#error |
| 반복 | 더 보기는 불러오는 동안 막힘 |
| 동시 변경 | 알림은 연 시각 기준(SCR-049#stale) |
| 데이터 노출 | 알림은 건수만. 손님 메시지·주문·연락처는 보이지 않음(G1, 05단계 E10) |
| 빈 응답·끊긴 응답 | 알림이 없으면 SCR-049#empty |
| 화면 상태 | 상태마다 360·1280 와이어프레임(`wireframes.html#SCR-049`) |
