# SCR-028 입금 대조 목록

- 경로: `/owner/payment-requests`
- 접근 권한: 사장님
- 상위 화면: SCR-014 사장님 로그인
- 화면 레이아웃: 사장님 화면(1280 왼쪽 메뉴, 360 위쪽 막대와 메뉴 버튼)
- 플로우: FL-007
- 관련 SPEC: SPEC-034, SPEC-033, SPEC-035, SPEC-037
- API: API-057
- 와이어프레임: `wireframes.html#SCR-028`(상태 6개, 360·1280)
- 목업: [`SCR-028-360`](../../research/cake-mockup-2026-11/canvas/project/SCR-028-360.dc.html)(normal·empty·error), [`SCR-028-1280`](../../research/cake-mockup-2026-11/canvas/project/SCR-028-1280.dc.html)(normal). 캔버스의 '사장님 화면' 페이지([09단계 README](../09-mockup/README.md) 2절)

목적: 사장님이 결제 확인을 요청받은 결제 안내와 기한이 다가오는 결제 안내를 모아 보고 은행 앱과 맞춰 볼 안내를 엽니다. (FL-007)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 결제 안내: 주문번호·종류(첫 결제·다시 낸 결제·차액 결제)·상태·금액·요청 금액·입금자 이름(손님이 넣은 이름, 넣지 않았으면 주문자 이름, REQ-176)·결제 기한·확인 요청 시각 | API-057 items |
| 다음 페이지 | API-057 nextCursor |

## 액션

| 액션 | 결과 | 실패 |
| --- | --- | --- |
| 상태 탭(확인 요청됨·열림·맞추는 중·기한 지남) | 그 상태의 안내를 다시 불러옴 | 주소 값이 틀리면(422) SCR-028#error |
| 안내 누르기 | 입금 대조(SCR-029) | 그 화면의 상태 |
| 더 보기 | 다음 페이지를 목록 아래에 추가로 불러옴 | 실패하면 목록 끝에 '다시 시도' |

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이 상태로 오는 응답 |
| --- | --- | --- |
| SCR-028#normal | 확인 요청된 안내를 맨 위에, 나머지는 결제 기한이 가까운 순. 1280: 표(주문번호·종류·금액·입금자·결제 기한·상태), 360: 카드. 기한까지 1시간 안이면 '곧 기한' 라벨 | API-057#200:claimed |
| SCR-028#loading | 레이아웃은 그대로 두고 데이터 자리에 회색 막대를 보임. 액션 버튼은 누를 수 없음 | (데이터를 불러오는 동안) |
| SCR-028#empty | '대조할 결제 안내가 없어요' | API-057#200:empty |
| SCR-028#error | 주소의 필터·페이지 값이 틀림(422 validation_failed): '입력한 내용을 확인해 주세요'와 '처음부터 보기'. 그 밖의 실패: '문제가 생겼어요. 다시 시도해 주세요'와 다시 시도 버튼, 추적 ID | API-057#422:validation_failed, API-057#default:internal |
| SCR-028#permission | 로그인이 없거나 만료됨(401 unauthenticated): 로그인 화면으로 이동하고, 로그인하면 이 화면으로 돌아옴('다시 로그인해 주세요'). 로그인한 사장님에게 가게가 아직 없음(404 shop_not_registered): 가게가 없으면 가게 등록(SCR-015)으로 보냄('가게를 먼저 등록해 주세요') | API-057#401:unauthenticated, API-057#404:shop_not_registered |
| SCR-028#stale | 목록은 연 시각 기준이라 그 뒤 바뀐 것이 안 보일 수 있음: 맨 위에 'HH:MM 기준'과 '새로 고침'. 다른 화면에서 처리하고 돌아오면 다시 불러옴. 결제 기한이 지난 안내는 '기한 지남' 탭으로 옮겨 감 | - |

06단계 계약(`api/openapi.yaml`)의 응답마다 화면 상태 하나입니다. 오류의 문구는 06단계 오류 코드 표의 '화면에 보이는 말'입니다.

| 응답 | 화면 상태 | 화면에 보이는 것 |
| --- | --- | --- |
| API-057#200:claimed | SCR-028#normal | 결제 확인 요청된 안내와 기한이 다가오는 안내 |
| API-057#200:empty | SCR-028#empty | '대조할 결제 안내가 없어요' |
| API-057#401:unauthenticated | SCR-028#permission | '다시 로그인해 주세요' |
| API-057#404:shop_not_registered | SCR-028#permission | '가게를 먼저 등록해 주세요' |
