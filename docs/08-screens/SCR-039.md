# SCR-039 운영규정 버전 이력

- 경로: `/owner/operating-rules/versions`
- 접근 권한: 사장님
- 상위 화면: SCR-038 운영규정
- 화면 레이아웃: 사장님 화면(1280 왼쪽 메뉴, 360 위쪽 막대와 메뉴 버튼)
- 플로우: FL-002
- 관련 SPEC: SPEC-005, SPEC-016
- API: API-022, API-023
- 와이어프레임: `wireframes.html#SCR-039`(상태 5개, 360·1280)
- 목업: [`SCR-039-360`](../../research/cake-mockup-2026-11/canvas/project/SCR-039-360.dc.html)(normal·empty·error), [`SCR-039-1280`](../../research/cake-mockup-2026-11/canvas/project/SCR-039-1280.dc.html)(normal). 캔버스의 '사장님 화면' 페이지([09단계 README](../09-mockup/README.md) 2절)

목적: 사장님이 이전 운영규정 버전 목록과 버전 하나(읽기 전용)를 봅니다. 주문마다 받은 버전으로 환불을 계산하므로 이전 버전도 남습니다. (FL-002)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 버전 목록: 버전·확정 시각·다음 버전으로 바뀐 시각(최신 순) | API-022 items |
| 버전 하나의 조문·기한·환불 | API-023 |

## 액션

| 액션 | 결과 | 실패 |
| --- | --- | --- |
| 버전 누르기 | 그 버전(/owner/operating-rules/versions/:version)의 조문을 읽기 전용으로 | 없는 버전(404)은 SCR-039#error와 버전 목록 링크 |
| 현재 운영규정으로 | 운영규정(SCR-038) | 그 화면의 상태 |

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이 상태로 오는 응답 |
| --- | --- | --- |
| SCR-039#normal | 1280: 왼쪽 버전 목록(버전·확정 시각, 현재 버전에 '현재'), 오른쪽 고른 버전의 조문·기한·단계별 환불. 위에 '이전 버전은 고칠 수 없어요. 그 버전으로 받은 주문은 이 조문으로 환불을 계산해요'. 360: 목록 화면과 버전 화면을 나눔 | API-022#200:versions, API-023#200:old_version |
| SCR-039#loading | 레이아웃은 그대로 두고 데이터 자리에 회색 막대를 보임. 액션 버튼은 누를 수 없음 | (데이터를 불러오는 동안) |
| SCR-039#empty | '아직 확정한 운영규정이 없어요'와 '운영규정 정하기'(SCR-038) | API-022#200:empty |
| SCR-039#error | 없거나 다른 가게의 운영규정 버전(404 not_found): '찾을 수 없어요'와 '버전 목록으로' 링크(SCR-039). 다른 가게 기록이 있는지는 말하지 않음(G1). 그 밖의 실패: '문제가 생겼어요. 다시 시도해 주세요'와 다시 시도 버튼, 추적 ID | API-022#default:internal, API-023#404:not_found, API-023#default:internal |
| SCR-039#permission | 로그인이 없거나 만료됨(401 unauthenticated): 로그인 화면으로 이동하고, 로그인하면 이 화면으로 돌아옴('다시 로그인해 주세요'). 로그인한 사장님에게 가게가 아직 없음(404 shop_not_registered): 가게가 없으면 가게 등록(SCR-015)으로 보냄('가게를 먼저 등록해 주세요') | API-022#401:unauthenticated, API-022#404:shop_not_registered, API-023#401:unauthenticated |
| stale (해당 없음) | 확정한 버전은 바뀌지 않음(REQ-027). 새 버전은 운영규정 화면에서 확정하고 돌아오면 다시 불러옴 |  |

## 응답과 상태

06단계 계약(`api/openapi.yaml`)의 응답마다 화면 상태 하나입니다. 오류의 문구는 06단계 오류 코드 표의 '화면에 보이는 말'입니다.

| 응답 | 화면 상태 | 화면에 보이는 것 |
| --- | --- | --- |
| API-022#200:versions | SCR-039#normal | 버전 목록(최신 순) |
| API-022#200:empty | SCR-039#empty | '아직 확정한 운영규정이 없어요' |
| API-022#401:unauthenticated | SCR-039#permission | '다시 로그인해 주세요' |
| API-022#404:shop_not_registered | SCR-039#permission | '가게를 먼저 등록해 주세요' |
| API-022#default:internal | SCR-039#error | '문제가 생겼어요. 다시 시도해 주세요' |
| API-023#200:old_version | SCR-039#normal | 그 버전의 조문(읽기 전용) |
| API-023#401:unauthenticated | SCR-039#permission | '다시 로그인해 주세요' |
| API-023#404:not_found | SCR-039#error | '찾을 수 없어요' |
| API-023#default:internal | SCR-039#error | '문제가 생겼어요. 다시 시도해 주세요' |
