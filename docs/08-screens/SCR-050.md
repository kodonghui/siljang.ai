# SCR-050 가게 기록 보기

- 경로: `/operator/shops/:shopId/records`
- 접근 권한: 운영자
- 상위 화면: SCR-046 운영자 로그인
- 화면 레이아웃: 운영자 화면(1280 왼쪽 메뉴, 360 위쪽 막대와 메뉴 버튼)
- 플로우: FL-014
- 관련 SPEC: SPEC-073, SPEC-074
- API: API-074, API-075, API-076, API-077
- 와이어프레임: `wireframes.html#SCR-050`(상태 9개, 360·1280)
- 목업: [`SCR-050-360`](../../research/cake-mockup-2026-11/canvas/project/SCR-050-360.dc.html)(normal·empty·error·confirm), [`SCR-050-1280`](../../research/cake-mockup-2026-11/canvas/project/SCR-050-1280.dc.html)(normal). 캔버스의 '운영자 화면' 페이지([09단계 README](../09-mockup/README.md) 2절)

목적: 운영자가 손님 문제·분쟁이나 사장님의 보관 기록 요청으로 한 가게의 주문·상담을 가린 값으로 찾아보고, 꼭 필요할 때만 사유를 적어 원래 값이나 보관 기록 하나, 상담의 대화 글 한 페이지를 엽니다. 본 것과 연 것은 접속기록에 남습니다. (FL-014)

## 액션

| 액션 | 결과 | 실패 |
| --- | --- | --- |
| 주문·상담 탭 | 그 종류의 기록을 다시 불러옴 | 주소의 값이 틀리면(422) SCR-050#error |
| 주문·상담 누르기 | 그 주문(API-076)이나 상담(API-075)을 가린 값으로 엶. 1280은 오른쪽, 360은 다른 화면 | 없는 기록(404)은 SCR-050#error, 지운 상담은 SCR-050#empty |
| 원래 값 열기·보관 기록 열기·대화 글 열기 | 사유를 적는 창(SCR-050#confirm)이 열림 | 원래 값을 두지 않는 번호(카드번호·긴 숫자)에는 버튼 대신 '원래 값을 두지 않아요' |
| 사유를 적고 열기 | 그 값 하나나 보고 있는 페이지의 대화 글을 읽기 전용으로 보임(SCR-050#done). 접속기록에 운영자·시각·접속지·대상·사유가 남음 | 사유가 5자보다 짧거나 200자를 넘음(422)·원래 값을 두지 않는 값(409 original_not_kept)은 SCR-050#error, 지워진 값과 지운 상담의 대화 글(409 original_erased)은 SCR-050#stale |
| 닫기 | 연 값을 화면에서 지우고 가린 값으로 돌아감. 다시 보려면 사유를 다시 적음 | 해당 없음(화면 안의 동작) |
| 더 보기 | 다음 페이지를 목록 아래에 추가로 불러옴 | 실패하면 목록 끝에 '다시 시도' |

| 접근 | 운영자 계정만. 사장님·손님은 이 화면과 원래 값 열기를 쓰지 못함(SPEC-073). 401은 SCR-050#permission(운영자 기록은 보이지 않음) |
| 입력 | 사유 5~200자. 비었거나 짧거나 넘으면 SCR-050#error의 필드 옆이고 열지 않음. 주소의 탭·페이지 값이 틀리면 SCR-050#error |
| 대상 | 없는 기록과 보관 기록이 된 주문의 주소는 SCR-050#error. 원래 값을 두지 않는 카드번호·긴 숫자는 '원래 값을 두지 않아요'(REQ-192) |
| 상태 변화 | 보관 기록이 된 주문은 목록에 주문번호·끝난 날·보관 기간만, 내용은 '보관 기록 열기'로(05단계 A22). 지운 상담은 SCR-050#empty, 연 뒤 지워진 값은 SCR-050#stale |
| 반복 | 같은 값을 다시 열어도 그때마다 사유를 적고 접속기록 한 행. '사유를 적고 열기'를 두 번 눌러도 요청은 한 번(같은 요청 키, SCR-050#submitting) |
| 동시 변경 | 목록과 기록은 연 시각 기준(SCR-050#stale) |
| 외부 서비스 | 접속기록을 남기지 못하면 기록과 원래 값을 보이지 않음(SCR-050#error, SPEC-074) |
| 데이터 노출 | 손님 이름·연락처·계좌번호·대화 속 번호는 가린 값, 상담의 대화 글은 보이지 않고 글자 수만(REQ-227), 알레르기 답은 있는지만, 사진은 장 수만(REQ-194). 연 값은 이 화면에만 보이고 저장·내려받기·복사 버튼이 없음. 로그·오류 보고에는 연 값이 없음(G6). 본 것과 연 것은 접속기록에(REQ-196) |
| 빈 응답·끊긴 응답 | 기록이 없으면 SCR-050#empty |
| 화면 상태 | 상태마다 360·1280 와이어프레임(`wireframes.html#SCR-050`) |
