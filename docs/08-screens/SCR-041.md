# SCR-041 카카오톡 채널 연결

- 경로: `/owner/kakao-channel`
- 접근 권한: 사장님
- 상위 화면: SCR-034 가게 설정
- 화면 레이아웃: 사장님 화면(1280 왼쪽 메뉴, 360 위쪽 막대와 메뉴 버튼)
- 플로우: FL-001
- 관련 SPEC: SPEC-008, SPEC-017
- API: API-030, API-031, API-032, API-079
- 와이어프레임: `wireframes.html#SCR-041`(상태 10개, 360·1280)
- 목업: [`SCR-041-360`](../../research/cake-mockup-2026-11/canvas/project/SCR-041-360.dc.html)(normal·empty·error), [`SCR-041-1280`](../../research/cake-mockup-2026-11/canvas/project/SCR-041-1280.dc.html)(normal). 캔버스의 '사장님 화면' 페이지([09단계 README](../09-mockup/README.md) 2절)

목적: 사장님이 연결할 가게 카카오톡 채널(오픈빌더 봇)과 카드 버튼이 부를 블록 다섯의 블록 ID를 정하고, 우리 스킬 설정 값과 한 번만 보이는 스킬 키를 오픈빌더에 옮긴 뒤 연결 확인(10분, 화면의 연결 문구와 시험 버튼 다섯)을 하고, 먼저 보내기 시험 안내의 결과를 봅니다. 스킬 키 바꾸기(REQ-237)와 봇 ID 찾는 법(DEC-28)도 여기서 봅니다. (FL-001)

## 케이스 유형

| 케이스 유형 | 화면에 보이는 것 |
| --- | --- |
| 접근 | 로그인한 사장님의 가게만. 401은 SCR-041#permission |
| 입력 | 봇 ID 1~64자, 채널 공개 ID 2~40자, 블록 ID 1~100자(빈칸 없음). 틀리면 SCR-041#error |
| 대상 | 다른 가게에 연결됐거나 다른 가게가 연결 확인 중인 채널은 SCR-041#error(운영자 알림, SCR-049). 다른 가게의 '연결 확인 중' 선점은 30분이 지나면 이 가게가 같은 봇을 넣을 때 풀림(REQ-238). 정하기 전이면 SCR-041#empty |
| 상태 변화 | 블록 ID가 하나라도 비면 연결 확인을 시작하지 않음(SCR-041#error). 화면의 연결 문구가 그 채널 대화창에서 와야 시험이 시작되고(REQ-238) 시험 버튼 다섯이 모두 닿아야 연결됨(REQ-206). 같은 봇의 블록 ID를 바꾸면 연결 확인 중으로 돌아감. 채널을 바꾸면 새 채널이 연결될 때 옛 채널은 그만 받음 |
| 반복 | 연결 확인을 여러 번 눌러도 연결은 하나(G2, SCR-041#checking). 스킬 키 바꾸기를 같은 요청 키로 다시 보내면 키를 다시 바꾸지 않고 같은 키를 보임 |
| 동시 변경 | 다른 기기의 저장과 동시에 일어나면 SCR-041#stale |
| 외부 서비스 | 10분 안에 연결 문구와 시험 버튼 다섯이 없으면 SCR-041#error와 사유 후보. 시험 안내가 닿지 않으면 SCR-041#event-off와 사유(REQ-180, REQ-181) |
| 데이터 노출 | 스킬 키(헤더 값)는 연결을 만들 때와 바꿀 때의 응답에만 한 번 보이고 서버도 저장하지 않아 다시 볼 수 없음(DEC-08, REQ-237). 잃었거나 샜으면 '스킬 키 바꾸기'. 연결 문구는 연결 확인 중에만 이 화면에(REQ-238) |
| 빈 응답·끊긴 응답 | 정하기 전이면 SCR-041#empty |
| 화면 상태 | 상태마다 360·1280 와이어프레임(`wireframes.html#SCR-041`) |
