# SCR-041 카카오톡 채널 연결

- 경로: `/owner/kakao-channel`
- 접근 권한: 사장님
- 상위 화면: SCR-034 가게 설정
- 화면 레이아웃: 사장님 화면(1280 왼쪽 메뉴, 360 위쪽 막대와 메뉴 버튼)
- 플로우: FL-001
- 관련 SPEC: SPEC-008
- API: API-030, API-031, API-032
- 와이어프레임: `wireframes.html#SCR-041`(상태 10개, 360·1280)
- 목업: [`SCR-041-360`](../../research/cake-mockup-2026-11/canvas/project/SCR-041-360.dc.html)(normal·empty·error), [`SCR-041-1280`](../../research/cake-mockup-2026-11/canvas/project/SCR-041-1280.dc.html)(normal). 캔버스의 '사장님 화면' 페이지([09단계 README](../09-mockup/README.md) 2절)

목적: 사장님이 연결할 가게 카카오톡 채널(오픈빌더 봇)과 카드 버튼이 부를 블록 넷의 블록 ID를 정하고, 우리 스킬 설정 값을 오픈빌더에 옮긴 뒤 연결 확인(10분, 테스트 메시지와 시험 버튼 넷)을 하고, 먼저 보내기 시험 안내의 결과를 봅니다. 봇 ID 찾는 법도 여기서 봅니다(OPEN-8). (FL-001)

## 액션

| 액션 | 결과 | 실패 |
| --- | --- | --- |
| 봇 ID·채널 공개 ID·블록 ID 저장 | '저장했어요. 아래 스킬 설정 값을 오픈빌더에 넣어 주세요'와 스킬 설정 값. 같은 봇의 블록 ID만 바꾸면 '블록 ID를 바꿨어요. 연결 확인을 다시 해 주세요'(연결 확인 중으로 돌아가고 다시 연결될 때까지 손님 메시지는 받지 않음) | 이미 다른 가게에 연결된 채널(409 channel_linked_elsewhere)은 SCR-041#error(운영자에게도 알림), 형식(422)은 필드 옆, 본 뒤 바뀜은 SCR-041#stale |
| 값 복사(스킬 주소·이벤트 이름·헤더 값) | 클립보드에 복사하고 '복사했어요' | 복사가 막힌 브라우저면 값을 선택해 둠 |
| 연결 확인 | 10분 동안 SCR-041#checking: 가게 채널에 아무 메시지나 보내고 답으로 오는 시험 버튼 4개를 차례로 눌러 달라는 안내. 몇 초마다 다시 읽고 닿은 블록을 n/4로 보임 | 블록 ID가 하나라도 비면(409 channel_setup_incomplete) SCR-041#error의 빈 필드, 봇·채널을 정하기 전(404 not_set)은 SCR-041#empty, 이미 확인 중이거나 연결됨(200 unchanged)은 지금 상태 그대로 |
| 시험 안내 다시 보내기(먼저 보내기 안 됨일 때) | 시험 안내를 다시 보내고 '먼저 보내기 확인 중'(API-032 event_recheck, SCR-041#checking) | 사유를 고치지 않았으면 다시 SCR-041#event-off |
| 봇 ID·블록 ID 찾는 법(펼치기) | 오픈빌더에서 봇을 열었을 때 주소의 /bot/ 다음 값이라는 안내와 예시, 버튼 블록 ID를 찾는 곳(W7, 개발 전 실제 화면으로 확인) | 해당 없음(화면 안 안내) |

| 입력 | 봇 ID 1~64자, 채널 공개 ID 2~40자, 블록 ID 1~100자(빈칸 없음). 틀리면 SCR-041#error |
| 대상 | 다른 가게에 연결된 채널은 SCR-041#error(운영자 알림, SCR-049). 정하기 전이면 SCR-041#empty |
| 상태 변화 | 블록 ID가 하나라도 비면 연결 확인을 시작하지 않음(SCR-041#error). 시험 버튼 넷이 모두 닿아야 연결됨(REQ-179). 같은 봇의 블록 ID를 바꾸면 연결 확인 중으로 돌아감. 채널을 바꾸면 새 채널이 연결될 때 옛 채널은 그만 받음 |
| 반복 | 연결 확인을 여러 번 눌러도 연결은 하나(G2, SCR-041#checking) |
| 동시 변경 | 다른 기기의 저장과 동시에 일어나면 SCR-041#stale |
| 외부 서비스 | 10분 안에 테스트 메시지와 시험 버튼 넷이 없으면 SCR-041#error와 사유 후보. 시험 안내가 닿지 않으면 SCR-041#event-off와 사유(REQ-180, REQ-181) |
| 데이터 노출 | 스킬 키(헤더 값)는 이 화면에만(DEC-08). 처음엔 마스킹하고 '보기'를 눌러야 보임 |
| 빈 응답·끊긴 응답 | 정하기 전이면 SCR-041#empty |
| 화면 상태 | 상태마다 360·1280 와이어프레임(`wireframes.html#SCR-041`) |
