# SCR-043 예약 링크

- 경로: `/owner/booking-link`
- 접근 권한: 사장님
- 상위 화면: SCR-034 가게 설정
- 화면 레이아웃: 사장님 화면(1280 왼쪽 메뉴, 360 위쪽 막대와 메뉴 버튼)
- 플로우: FL-001
- 관련 SPEC: SPEC-010
- API: API-037
- 와이어프레임: `wireframes.html#SCR-043`(상태 6개, 360·1280)
- 목업: [`SCR-043-360`](../../research/cake-mockup-2026-11/canvas/project/SCR-043-360.dc.html)(normal·empty·error), [`SCR-043-1280`](../../research/cake-mockup-2026-11/canvas/project/SCR-043-1280.dc.html)(normal). 캔버스의 '사장님 화면' 페이지([09단계 README](../09-mockup/README.md) 2절)

목적: 사장님이 예약 링크와 아직 채우지 않은 조건(영업 신고 확인·가격표·운영규정·영업 캘린더·결제 수단·채널 연결·개인정보 처리방침)을 보고, 링크를 복사해 카카오톡 채널과 인스타그램 프로필에 등록합니다. (FL-001)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 상태(발급됨·조건 미충족)와 예약 링크 주소·발급 시각 | API-037 status·url·issuedAt |
| 미충족 조건(7개까지) | API-037 missing |
| 넣으면 좋은 것(픽업 장소) | API-037 recommended |

## 액션

| 액션 | 결과 | 실패 |
| --- | --- | --- |
| 링크 복사 | '복사했어요' | 복사가 막힌 브라우저면 주소를 선택해 둠 |
| 예약 링크 페이지 열기 | 새 탭에서 손님이 보는 예약 링크 페이지(SCR-001) | 그 화면의 상태 |
| 조건 누르기 | 영업 신고(SCR-035)·가격표(SCR-036)·운영규정(SCR-038)·영업 캘린더 설정(SCR-033)·결제 수단(SCR-040)·채널 연결(SCR-041)로 이동. 처리방침은 운영자가 국외 이전 항목을 채울 때까지 기다림 | 그 화면의 상태 |

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이 상태로 오는 응답 |
| --- | --- | --- |
| SCR-043#normal | 발급됨(issued): 예약 링크 주소(크게)·'복사'·'예약 링크 페이지 열기', 발급 시각, '카카오톡 채널 프로필과 인스타그램 프로필에 이 주소를 넣어 주세요'. 픽업 장소가 비었으면 아래 '픽업 장소를 넣으면 전날 안내에 함께 나가요' | API-037#200:issued |
| SCR-043#loading | 레이아웃은 그대로 두고 데이터 자리에 회색 막대를 보임. 액션 버튼은 누를 수 없음 | (데이터를 불러오는 동안) |
| SCR-043#empty | 조건 미충족(not_ready): '예약 링크를 만들려면 아래를 마쳐 주세요'와 조건 7개 목록(영업 신고 확인·가격표·운영규정·영업 캘린더·결제 수단·채널 연결·개인정보 처리방침. 마친 것은 체크와 '마침', 남은 것은 그 화면 링크: 영업 신고 확인은 '운영자가 확인하고 있어요', 결제 수단은 '결제 수단 등록하기'). 처리방침은 '운영자가 준비하고 있어요'. 예약 링크 주소와 '복사'는 없음 | API-037#200:not_ready |
| SCR-043#error | 불러오기 실패: '문제가 생겼어요. 다시 시도해 주세요'와 다시 시도 버튼, 추적 ID | API-037#default:internal |
| SCR-043#permission | 로그인이 없거나 만료됨(401 unauthenticated): 로그인 화면으로 이동하고, 로그인하면 이 화면으로 돌아옴('다시 로그인해 주세요'). 로그인한 사장님에게 가게가 아직 없음(404 shop_not_registered): 가게가 없으면 가게 등록(SCR-015)으로 보냄('가게를 먼저 등록해 주세요') | API-037#401:unauthenticated, API-037#404:shop_not_registered |
| SCR-043#stale | 목록은 연 시각 기준이라 그 뒤 바뀐 것이 안 보일 수 있음: 맨 위에 'HH:MM 기준'과 '새로 고침'. 다른 화면에서 처리하고 돌아오면 다시 불러옴. 조건은 다른 설정 화면에서 바뀌므로 돌아오면 다시 불러옴. 연 뒤 운영자가 영업 신고를 확인할 수 있음 | - |

## 응답과 상태

06단계 계약(`api/openapi.yaml`)의 응답마다 화면 상태 하나입니다. 오류의 문구는 06단계 오류 코드 표의 '화면에 보이는 말'입니다.

| 응답 | 화면 상태 | 화면에 보이는 것 |
| --- | --- | --- |
| API-037#200:issued | SCR-043#normal | 예약 링크 주소와 복사 버튼 |
| API-037#200:not_ready | SCR-043#empty | 미충족 조건 목록과 각 설정 화면 링크 |
| API-037#401:unauthenticated | SCR-043#permission | '다시 로그인해 주세요' |
| API-037#404:shop_not_registered | SCR-043#permission | '가게를 먼저 등록해 주세요' |
| API-037#default:internal | SCR-043#error | '문제가 생겼어요. 다시 시도해 주세요' |

## 케이스 유형

| 케이스 유형 | 화면에 보이는 것 |
| --- | --- |
| 접근 | 로그인한 사장님의 가게만. 401은 SCR-043#permission |
| 대상 | 가게가 없으면 SCR-043#permission |
| 상태 변화 | 조건이 남으면 SCR-043#empty. 영업 신고 확인 전·결제 수단 등록 전에는 다른 조건이 다 돼도 링크가 없음(REQ-103, REQ-164) |
| 동시 변경 | 조건 둘이 동시에 채워져도 링크는 하나(G2). 이미 낸 링크는 같은 주소로 유지 |
| 데이터 노출 | 링크 주소에 내부 ID 없음(가게 주소 이름만) |
| 빈 응답·끊긴 응답 | 조건 미충족은 SCR-043#empty |
| 화면 상태 | 상태마다 360·1280 와이어프레임(`wireframes.html#SCR-043`) |
