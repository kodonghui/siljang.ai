# SCR-036 가격표와 도안

- 경로: `/owner/price-list`
- 접근 권한: 사장님
- 상위 화면: SCR-034 가게 설정
- 화면 레이아웃: 사장님 화면(1280 왼쪽 메뉴, 360 위쪽 막대와 메뉴 버튼)
- 플로우: FL-001, FL-002
- 관련 SPEC: SPEC-004
- API: API-016, API-017, API-007
- 와이어프레임: `wireframes.html#SCR-036`(상태 8개, 360·1280)
- 목업: [`SCR-036-360`](../../research/cake-mockup-2026-11/canvas/project/SCR-036-360.dc.html)(normal·empty·error), [`SCR-036-1280`](../../research/cake-mockup-2026-11/canvas/project/SCR-036-1280.dc.html)(normal). 캔버스의 '사장님 화면' 페이지([09단계 README](../09-mockup/README.md) 2절)

목적: 사장님이 크기·맛·디자인·추가 옵션의 값과 옵션 규칙, 기본 디자인 범위, 도안을 고쳐 새 가격표 버전으로 저장합니다. 이전 버전은 남고 새 견적은 새 버전으로만 계산합니다. (FL-001, FL-002)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 현재 버전 번호와 저장 시각 | API-016 version·createdAt |
| 옵션: 그룹(크기·맛·디자인·추가)·이름(1~30자)·표시 방식(확정·부터·범위)·금액·최대 금액·기본 디자인 포함·순서(100개까지) | API-016 options |
| 옵션 규칙: 함께 못 고름·더하는 값(500개까지) | API-016 rules |
| 도안: 이름·도안 그림·연결 옵션·기본 디자인 포함(50장까지) | API-016 designs |
| 도안 그림 올리기 결과(10MB) | API-007 design_image |
| 저장 결과 | API-017 outcome·priceList |

## 액션

| 액션 | 결과 | 실패 |
| --- | --- | --- |
| 옵션·규칙·도안 고치기 | 화면 안에서만 바뀌고 '저장 전' 표시 | 필드 한도는 입력하는 즉시 필드 옆에 보임 |
| 저장 | 새 버전: '저장했어요. 가격표 버전 {n}'. 바꾼 것이 없으면 '바뀐 것이 없어 새 버전을 만들지 않았어요' | 필드 오류·옵션 규칙 충돌·한도(422)는 SCR-036#error의 필드·충돌한 행 옆, 다른 기기에서 먼저 저장함(409 version_conflict)은 SCR-036#stale |
| 도안 그림 올리기 | 미리보기와 '올렸어요'(1시간 안에 저장해야 씀) | 10MB 넘음(413)·사진 아님(422)·저장소 장애(503)는 SCR-036#error |
| 버전 이력 | 가격표 버전 이력(SCR-037) | 그 화면의 상태 |

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이 상태로 오는 응답 |
| --- | --- | --- |
| SCR-036#normal | 위에 '가격표 버전 n · YYYY-MM-DD 저장'과 '버전 이력'. 그룹 탭(크기·맛·디자인·추가)마다 표(옵션 이름·표시 방식·금액·기본 디자인), 옵션 규칙 표(옵션 A·옵션 B·함께 못 고름/더하는 값), 도안 격자(도안 그림·이름). 고친 셀은 굵게, 아래 고정 막대에 '저장 전 바뀐 셀 n개'와 '저장' | API-016#200:current, API-007#201:purpose=design_image |
| SCR-036#loading | 레이아웃은 그대로 두고 데이터 자리에 회색 막대를 보임. 액션 버튼은 누를 수 없음. 표의 행 자리는 회색 막대 네 줄 | (데이터를 불러오는 동안) |
| SCR-036#empty | 가격표를 아직 만들지 않음(404 not_set): 그룹 넷의 빈 표와 '첫 가격표를 만들어 주세요'. 저장하면 버전 1 | API-016#404:not_set |
| SCR-036#error | 입력이 한도나 형식에 맞지 않음(422 validation_failed): 필드 옆에 '입력한 내용을 확인해 주세요'와 필드마다의 사유. 넣은 값은 그대로 둠(값은 0원~1,000만 원의 원 단위, 옵션 100개, 도안 50장). 옵션 규칙끼리 충돌함(422): 충돌한 행을 굵게 표시하고 '같은 조합이 허용이자 금지예요'. 도안 그림이 10MB를 넘음(413): 06단계 file_too_large 문구. 저장소 장애(503): storage_unavailable 문구. 같은 요청 키로 다른 내용을 보냄(422 idempotency_key_reused): '다시 시도해 주세요'. 새 요청 키로 다시 보냄. 그 밖의 실패: '문제가 생겼어요. 다시 시도해 주세요'와 다시 시도 버튼, 추적 ID | API-016#default:internal, API-017#422:validation_failed, API-017#422:idempotency_key_reused, API-017#default:internal, API-007#413:file_too_large, API-007#422:validation_failed, API-007#503:storage_unavailable, API-007#default:internal |
| SCR-036#permission | 로그인이 없거나 만료됨(401 unauthenticated): 로그인 화면으로 이동하고, 로그인하면 이 화면으로 돌아옴('다시 로그인해 주세요'). 로그인한 사장님에게 가게가 아직 없음(404 shop_not_registered): 가게가 없으면 가게 등록(SCR-015)으로 보냄('가게를 먼저 등록해 주세요') | API-016#401:unauthenticated, API-016#404:shop_not_registered, API-017#401:unauthenticated, API-017#404:shop_not_registered, API-007#401:unauthenticated |
| SCR-036#stale | 다른 기기에서 먼저 저장함(409 version_conflict): '그 사이 바뀌었어요. 지금 상태를 확인해 주세요'와 다시 읽은 지금 상태. 고치던 값은 버리지 않고 '내 변경 다시 적용'으로 지금 버전 위에 다시 얹을 수 있음(G3) | API-017#409:version_conflict |
| SCR-036#submitting | 누른 버튼이 '처리하고 있어요'로 바뀌고 이 화면의 다른 액션과 함께 막힘. 첫 요청을 아직 처리하는 중이면(409 request_in_progress) 1초 뒤 같은 요청 키로 다시 보내고, 결과는 한 번만 보임 | API-017#409:request_in_progress |
| SCR-036#done | 저장(created): '저장했어요. 가격표 버전 {n}'. 바뀐 것 없음(unchanged): '바뀐 것이 없어 새 버전을 만들지 않았어요' | API-017#201:created, API-017#200:unchanged |

## 케이스 유형

| 케이스 유형 | 화면에 보이는 것 |
| --- | --- |
| 접근 | 로그인한 사장님의 가게만. 401은 SCR-036#permission |
| 입력 | 값 0원~1,000만 원, 옵션 이름 1~30자, 규칙 충돌 없음. 틀리면 SCR-036#error |
| 대상 | 이전 버전은 고칠 수 없고 SCR-037에서 읽기만(REQ-027). 처음이면 SCR-036#empty |
| 상태 변화 | 바꾼 것이 없으면 새 버전을 만들지 않음(SCR-036#done의 unchanged) |
| 반복 | 저장을 두 번 눌러도 버전은 하나 오름(G2) |
| 동시 변경 | 다른 기기에서 먼저 저장했으면 SCR-036#stale(G3) |
| 한도 | 옵션 100개·규칙 500개·도안 50장·도안 그림 10MB(SCR-036#error) |
| 외부 서비스 | 도안 그림 저장 실패(503)는 SCR-036#error |
| 데이터 노출 | 계산 근거는 사장님 화면에 전부, 손님에게는 금액·표시 방식·유효 기한만(SPEC-013) |
| 빈 응답·끊긴 응답 | 가격표가 없으면 SCR-036#empty |
| 화면 상태 | 상태마다 360·1280 와이어프레임(`wireframes.html#SCR-036`) |
