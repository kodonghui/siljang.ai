# SCR-009 취소 카드

- 경로: `kakao:shop/card/cancel`
- 접근 권한: 주문한 손님
- 상위 화면: SCR-007 내 주문 보기
- 화면 레이아웃: 카카오톡 채널 대화 화면(1280은 PC 카카오톡 창)
- 플로우: FL-009
- 관련 SPEC: SPEC-046, SPEC-016, SPEC-069
- API: API-071
- 와이어프레임: `wireframes.html#SCR-009`(상태 6개, 360·1280)
- 목업: [`SCR-009-360`](../../research/cake-mockup-2026-11/canvas/project/SCR-009-360.dc.html)(normal·expired·error), [`SCR-009-1280`](../../research/cake-mockup-2026-11/canvas/project/SCR-009-1280.dc.html)(normal). 캔버스의 '손님 화면' 페이지([09단계 README](../09-mockup/README.md) 2절)

목적: 주문한 손님이 지금 취소하면 받는 환불(가게 규칙 계산값과 쓴 조문 이름)을 보고 취소를 누릅니다. (FL-009)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 주문 요약 | API-071 카드(처음 카드는 SCR-003의 API-070 card_shown) |
| 지금 취소하면 받는 환불 금액과 쓴 조문 이름 | API-071 카드(SPEC-016) |

## 액션

| 액션 | 결과 | 실패 |
| --- | --- | --- |
| 취소 | 주문을 '손님이 취소함'으로 두고 자리를 풂(결제 기한 지난 주문은 자리가 이미 풀려 있음, 1-2). 확인된 결제가 있으면 사장님께 환불 정할 일, 결제 전이면 환불 없이 취소(SPEC-046) | 받은 주문·이미 취소된 주문은 SCR-009#stale, 카드 뒤 환불 금액이 바뀌었으면(맞춤 재료 주문·제작 시작) SCR-009#stale의 새 카드, 30분이 지났으면 SCR-009#expired |
| 안 할래요 | 아무것도 남기지 않고 '알겠어요. 더 궁금한 것이 있으면 말씀해 주세요' | 서버 오류면 SCR-009#error |

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이 상태로 오는 응답 |
| --- | --- | --- |
| SCR-009#normal | 카드 하나: '주문 취소', 주문번호·픽업 일시, '지금 취소하면 환불 {n}원({조문 이름})'(결제 전이면 '결제 전이라 환불할 금액이 없어요'), 버튼 '취소'·'안 할래요' | - |
| SCR-009#done | 결제한 주문은 '주문을 취소했어요. 환불은 사장님이 정한 뒤 알려 드려요', 결제 전 주문은 '주문을 취소했어요'. 같은 카드를 다시 누르면 같은 말(card_used) | API-071#200:order_cancelled, API-071#200:declined, API-071#200:card_used |
| SCR-009#stale | 카드 뒤 환불 금액이 바뀜(card_stale): '내용이 바뀌었어요…'와 새 금액의 새 카드. 받은 주문·이미 취소된 주문(not_allowed_now): '지금은 할 수 없어요: 이미 받은 주문이에요' | API-071#200:card_stale, API-071#200:not_allowed_now |
| SCR-009#expired | 보낸 지 30분이 지난 카드를 누름(card_expired): '시간이 지나 새 카드를 보내 드려요'와 지금 값으로 만든 새 카드. 아무것도 남지 않음 | API-071#200:card_expired |
| SCR-009#permission | 카드를 받은 사용자가 아님(card_not_yours): '이 버튼은 카드를 받은 분만 누를 수 있어요'. 아무것도 남지 않음. 그 사이 채널 연결이 끊긴 가게(not_accepting): '아직 상담을 받지 않아요. 가게로 연락해 주세요: {가게 연락처}' | API-071#200:card_not_yours, API-071#200:not_accepting |
| SCR-009#error | 쓰기 하나가 실패해 하나도 남기지 않음(retry_needed): '다시 눌러 주세요'. 서버 오류(server_error): '잠시 뒤 다시 말씀해 주세요'. 스킬 키가 틀리거나 형식이 아니거나 예상하지 못한 실패(401·422·default): 카카오톡이 자기 오류 말을 보임(우리 문구 없음, DEC-07). 서버 로그에 추적 ID | API-071#200:retry_needed, API-071#200:server_error, API-071#401:skill_key_invalid, API-071#422:validation_failed, API-071#default:internal |
| loading (해당 없음) | 버튼을 누른 뒤 답이 올 때까지는 카카오톡이 자기 표시를 함. 우리가 그릴 것이 없음 |  |
| empty (해당 없음) | 카드는 서버가 저장된 값이 있을 때만 만들어 보임(SPEC-069). 빈 카드는 없음 |  |

## 응답과 상태

06단계 계약(`api/openapi.yaml`)의 응답마다 화면 상태 하나입니다. 오류의 문구는 06단계 오류 코드 표의 '화면에 보이는 말'입니다.

| 응답 | 화면 상태 | 화면에 보이는 것 |
| --- | --- | --- |
| API-071#200:allergy_saved | 나오지 않음 | 알레르기 정보 카드(SCR-004#allergy)의 결과라 이 카드에서는 나오지 않음 |
| API-071#200:allergy_declined | 나오지 않음 | 알레르기 정보 카드(SCR-004#allergy)의 결과라 이 카드에서는 나오지 않음 |
| API-071#200:orderer_saved | 나오지 않음 | 주문자 정보 블록(SCR-004#orderer)의 결과라 이 카드에서는 나오지 않음 |
| API-071#200:order_requested | 나오지 않음 | 이 카드에서는 나오지 않음(SCR-004 주문 요청 카드의 결과) |
| API-071#200:payment_claimed | 나오지 않음 | 이 카드에서는 나오지 않음(SCR-006 결제 확인 요청 카드의 결과) |
| API-071#200:change_requested | 나오지 않음 | 이 카드에서는 나오지 않음(SCR-008 변경 요청 카드의 결과) |
| API-071#200:order_cancelled | SCR-009#done | 결제한 주문: 주문을 취소했어요. 환불은 사장님이 정한 뒤 알려 드려요 / 결제 전 주문: 주문을 취소했어요 |
| API-071#200:issue_reported | 나오지 않음 | 이 카드에서는 나오지 않음(SCR-010 문제 신고 카드의 결과) |
| API-071#200:photo_consent_saved | 나오지 않음 | 완성 사진 안내의 사진 게시 동의 카드 결과라 이 카드에서는 나오지 않음(SCR-011#photo-consent) |
| API-071#200:consent_withdrawn | 나오지 않음 | 이 카드에서는 나오지 않음(SCR-013 사진 게시 동의 철회 카드의 결과) |
| API-071#200:declined | SCR-009#done | '알겠어요. 더 궁금한 것이 있으면 말씀해 주세요' |
| API-071#200:input_invalid | 나오지 않음 | 주문자 정보·알레르기 답·입금자 이름 블록(SCR-004#orderer, SCR-004#allergy, SCR-006#depositor)에서만 나옴 |
| API-071#200:card_stale | SCR-009#stale | 내용이 바뀌었어요. 새 카드를 확인해 주세요 + 새 카드 |

| API-071#200:channel_linked | 나오지 않음 | 채널 연결 확인의 시험 버튼 결과라 이 카드에서는 나오지 않음(SCR-003#link-test) |

## 케이스 유형

| 케이스 유형 | 화면에 보이는 것 |
| --- | --- |
| 접근 | 카드를 받은 같은 카카오 사용자만 누름. 다른 사람은 SCR-009#permission, 스킬 키가 틀리면 SCR-009#error |
| 입력 | 카드 값은 서버 기록에서만 오고 손님 말로 바꿀 수 없음. 스킬 요청 형식이 아니면 SCR-009#error |
| 대상 | 지금 상태에서 받을 수 없는 명령은 '지금은 할 수 없어요: {지금 상태}'(SCR-009#stale) |
| 상태 변화 | 버전이 바뀐 카드는 SCR-009#stale, 30분이 지난 카드는 SCR-009#expired. 둘 다 새 카드를 보내고 아무것도 남기지 않음 |
| 반복 | 같은 카드를 다시 누르면 처음 결과를 다시 보냄(SCR-009#done, card_used). 명령은 한 번 |
| 동시 변경 | 카드를 보낸 뒤 다른 쓰기가 먼저 이기면 SCR-009#stale |
| 외부 서비스 | 트랜잭션의 쓰기 하나가 실패하면 하나도 남기지 않고 '다시 눌러 주세요'(SCR-009#error) |
| 데이터 노출 | 카드와 결과에 다른 손님 정보·내부 ID(주문번호 밖)·오류 내용 없음(G6). 서버 오류도 '잠시 뒤 다시 말씀해 주세요'만 |
| AI 답 | AI는 환불 금액을 스스로 말하지 않고 카드의 계산값만 말함(SPEC-046). 카드 값은 서버 기록에서만(SPEC-069) |
| 화면 상태 | 상태마다 360·1280 와이어프레임(`wireframes.html#SCR-009`) |

## 긴 글과 좁은 화면

| 항목 | 한도 | 화면에서 |
| --- | --- | --- |
| 카드 설명 | 카드의 제목과 설명을 합쳐 400자, 한 응답의 출력 3개(카카오 스킬 응답 형식 문서, 2026-11-13 읽음) | 넘는 내용은 카드 앞의 글 말풍선(1,000자)으로 나눔. 버튼 이름은 14자 안 |
| 좁은 화면 | 360 | 말풍선은 카카오톡이 줄바꿈해 렌더링함. 1280 프레임은 PC 카카오톡 대화창(너비 약 480px로 가정) |
| 조문 이름 | 운영규정 조문 이름 | 금액 뒤 괄호에 하나. 여럿이면 쉼표로 |
