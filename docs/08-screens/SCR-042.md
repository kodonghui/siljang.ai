# SCR-042 장부 연결

- 경로: `/owner/ledger`
- 접근 권한: 사장님
- 상위 화면: SCR-034 가게 설정
- 화면 레이아웃: 사장님 화면(1280 왼쪽 메뉴, 360 위쪽 막대와 메뉴 버튼)
- 플로우: FL-001, FL-013
- 관련 SPEC: SPEC-009, SPEC-064
- API: API-033, API-034, API-035, API-036
- 와이어프레임: `wireframes.html#SCR-042`(상태 9개, 360·1280)
- 목업: [`SCR-042-360`](../../research/cake-mockup-2026-11/canvas/project/SCR-042-360.dc.html)(normal·empty·error), [`SCR-042-1280`](../../research/cake-mockup-2026-11/canvas/project/SCR-042-1280.dc.html)(normal). 캔버스의 '사장님 화면' 페이지([09단계 README](../09-mockup/README.md) 2절)

목적: 사장님이 구글 계정 권한에 동의해 구글 시트 장부를 연결·다시 연결·해제합니다. 장부에 못 적은 주문이 있으면 다시 연결 할 일이 이 화면으로 옵니다. (FL-001, FL-013)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 연결 상태(연결됨·권한 끊김·해제됨) | API-033 status |
| 구글 시트와 탭 이름, 우리 열(헤더·열 문자), 오른쪽 빈 열로 옮겨 만들었는지 | API-033 spreadsheetId·sheetName·columns·movedRight |
| 못 적은 주문 수와 실패가 시작된 시각, 연결·해제 시각 | API-033 unwrittenCount·failingSince·linkedAt·unlinkedAt |
| 구글 권한 요청 주소(10분) | API-034 authorizationUrl·state·expiresAt |
| 연결·해제 결과와 남겨 둔 쓰기 수 | API-035 outcome·ledger, API-036 outcome·keptWrites |

## 액션

| 액션 | 결과 | 실패 |
| --- | --- | --- |
| 구글 계정 연결 | 구글 권한 요청 화면으로 갔다가 돌아오면(/owner/ledger/callback) 구글 시트 주소와 탭 이름을 고르고 '연결' | 가게가 없음은 SCR-042#permission, 주소 값이 틀림(422)은 SCR-042#error |
| 연결(구글 시트를 고른 뒤) | '장부를 연결했어요'. 같은 이름의 열이 있으면 '같은 이름의 열이 있어 우리 열을 오른쪽 빈 열에 만들었어요'. 다시 연결이면 '다시 연결했어요. 못 적은 주문 {n}건을 다시 적어요' | 구글 권한 거부(422 google_authorization_failed)·구글 시트를 열 수 없음(422 sheet_not_accessible)·구글 장애(503)는 SCR-042#error, 본 뒤 바뀜은 SCR-042#stale |
| 연결 해제 | '연결을 해제했어요. 기다리던 쓰기 {n}건은 다시 연결하면 적어요' | 이미 해제됨(200 unchanged)은 SCR-042#done, 연결 전(404 not_set)은 SCR-042#empty |

## 케이스 유형

| 케이스 유형 | 화면에 보이는 것 |
| --- | --- |
| 접근 | 로그인한 사장님의 가게만. 401은 SCR-042#permission |
| 입력 | 같은 이름의 열이 있으면 우리 열을 오른쪽 빈 열에 만들고 알림(SCR-042#done의 moved_right). 주소 값이 틀리면 SCR-042#error |
| 대상 | 구글 시트를 열 수 없으면 SCR-042#error. 연결 전이면 SCR-042#empty |
| 상태 변화 | 권한이 끊기거나 해제됐으면 SCR-042#reconnect. 다시 연결하면 못 적은 주문을 다시 적음 |
| 반복 | 연결·해제를 두 번 눌러도 한 번(SCR-042#done의 unchanged) |
| 동시 변경 | 다른 기기의 저장과 동시에 일어나면 SCR-042#stale |
| 외부 서비스 | 구글 권한 거부·장애는 SCR-042#error. 24시간 계속 실패하거나 권한이 끊기면 SCR-042#reconnect와 할 일(SPEC-064) |
| 데이터 노출 | 구글 토큰은 화면·주소·로그에 없음(REQ-135). 장부에 알레르기는 적지 않음 |
| 빈 응답·끊긴 응답 | 연결 전은 SCR-042#empty |
| 화면 상태 | 상태마다 360·1280 와이어프레임(`wireframes.html#SCR-042`) |
