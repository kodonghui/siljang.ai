# SCR-019 사장님 알림

- 경로: `kakao:service/chat`
- 접근 권한: 사장님
- 상위 화면: SCR-016 할 일 목록
- 화면 레이아웃: 카카오톡 채널 대화 화면(1280은 PC 카카오톡 창)
- 플로우: FL-001, FL-002, FL-005, FL-006, FL-007, FL-008, FL-009, FL-011
- 관련 SPEC: SPEC-067, SPEC-003, SPEC-024, SPEC-006
- API: 없음(서버가 보내는 안내만 보임)
- 와이어프레임: `wireframes.html#SCR-019`(상태 4개, 360·1280)
- 목업: [`SCR-019-360`](../../research/cake-mockup-2026-11/canvas/project/SCR-019-360.dc.html)(normal·not-sent·error), [`SCR-019-1280`](../../research/cake-mockup-2026-11/canvas/project/SCR-019-1280.dc.html)(normal). 캔버스의 '사장님 화면' 페이지([09단계 README](../09-mockup/README.md) 2절)

목적: 사장님이 우리 서비스 카카오톡 채널로 할 일 알림(종류와 할 일 목록 주소)을 받고 눌러 할 일 목록을 엽니다. 결제 받을 계좌가 바뀌면 할 일 없이 알림을 받고 결제 수단을 엽니다. 알림은 우리 채널의 봇이 Event API로 사장님의 카카오 로그인 사용자 번호에 보냅니다(REQ-183). (FL-001, FL-002, FL-005, FL-006, FL-007, FL-008, FL-009, FL-011)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 할 일 종류와 할 일 목록 주소(손님 연락처·계좌·알레르기 없음) | 서버 안내 SPEC-067 |
| 지연 뒤 다시 알림(결제 확인 요청·금액 불일치·환불 결정 포함, REQ-215) | 서버 안내 SPEC-024 |
| 영업 신고 확인됨·보류 사유 | 서버 안내 SPEC-003 |
| 결제 받을 계좌가 바뀜과 결제 수단 주소(계좌번호 없음) | 서버 안내 SPEC-067, SPEC-006 |

## 액션

| 액션 | 결과 | 실패 |
| --- | --- | --- |
| 할 일 목록 열기(버튼) | 사장님 화면의 할 일 목록(SCR-016). 로그인이 없으면 로그인 뒤 그 화면 | 그 화면의 상태 |
| 결제 수단 보기(버튼, 계좌가 바뀐 알림) | 사장님 화면의 결제 수단(SCR-040). 로그인이 없으면 로그인 뒤 그 화면 | 그 화면의 상태 |

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이 상태로 오는 응답 |
| --- | --- | --- |
| SCR-019#normal | 말풍선 하나: '{할 일 종류}가 생겼어요'와 버튼 '할 일 목록 열기'. 같은 종류가 1분 안에 여럿이면 '{종류} n건'으로 묶음. 지연 뒤 다시 알림은 '아직 답하지 않은 {종류}가 있어요'. 영업 신고 결과는 '영업 신고가 확인됐어요' 또는 '영업 신고가 보류됐어요: {사유}'. 결제 받을 계좌를 바꾸면 '결제 받을 계좌가 바뀌었어요'와 버튼 '결제 수단 보기'(할 일은 만들지 않음, 계좌번호 없음, REQ-198) | - |
| SCR-019#not-sent | 사장님이 우리 서비스 채널 친구가 아님(로그인 때의 채널 관계 조회나 발송 결과의 '채널 친구 아님'으로 앎, REQ-183): 알림이 가지 않고 '못 보냄'으로 남음. 할 일은 할 일 목록에만 쌓이고 사장님 화면 맨 위에 채널 추가 배너(SCR-016#not-sent) | - |
| SCR-019#error | 카카오 보내기 실패: 카카오가 요청을 받지 않거나 발송 결과가 스킬·카카오 오류면 1분·5분·30분 뒤 다시 보내고 그래도 안 되면 할 일 목록에만 남김(G4). 닿았는지는 발송 결과로 확인한 뒤에만 '보냄'(REQ-182). 사장님에게 오류는 보이지 않음 | - |
| SCR-019#stale | 알림을 받은 뒤 할 일이 이미 처리됐을 수 있음: 알림에는 종류와 주소만 있고, 열면 할 일 목록이 지금 상태를 보임 | - |
| loading (해당 없음) | 서버가 먼저 보내는 말풍선이라 불러오는 동안이 없음 |  |
| empty (해당 없음) | 보낼 할 일이 있을 때만 생김 |  |
| permission (해당 없음) | 우리 서비스 채널 1:1 대화라 그 사장님에게만 보임. 알림 글에 손님 정보 없음 |  |

## 케이스 유형

| 케이스 유형 | 화면에 보이는 것 |
| --- | --- |
| 상태 변화 | 사장님이 채널 친구가 아니면 SCR-019#not-sent. 이미 처리된 할 일은 SCR-019#stale |
| 반복 | 할 일마다 알림 한 번, 지연 뒤 다시 알림 한 번(SPEC-024, REQ-154). 계좌가 바뀐 알림은 바꿀 때마다 한 번 |
| 한도 | 같은 종류가 1분 안에 여럿이면 하나로 묶음(SPEC-067) |
| 외부 서비스 | 카카오가 받지 않거나 발송 결과가 스킬·카카오 오류면 1분·5분·30분 뒤 다시, 그래도 안 되면 SCR-019#error처럼 할 일 목록에만(G4). 발송 결과가 '채널 친구 아님'이면 SCR-019#not-sent |
| 데이터 노출 | 알림 글에 손님 연락처·계좌·알레르기 없음(SPEC-067). 종류와 주소만. 계좌가 바뀐 알림에도 계좌번호 없음(REQ-198) |
| 화면 상태 | 상태마다 360·1280 와이어프레임(`wireframes.html#SCR-019`) |
