# SCR-001 예약 링크 페이지

- 경로: `/s/:slug`
- 접근 권한: 비로그인
- 상위 화면: 없음(루트)
- 화면 레이아웃: 손님 웹 페이지(360 한 열, 1280 가운데 열)
- 플로우: FL-001, FL-002, FL-003, FL-006, FL-007, FL-012
- 관련 SPEC: SPEC-011, SPEC-014, SPEC-063
- API: API-038
- 와이어프레임: `wireframes.html#SCR-001`(상태 6개, 360·1280)

목적: 손님이 가게의 포트폴리오·현재 버전 가격표·오늘부터 60일의 빈 날짜·가게 신원 정보를 보고 '문의하기'로 가게 카카오톡 채널 상담을 엽니다. 사장님은 발급된 링크가 손님에게 어떻게 보이는지 확인합니다. (FL-001, FL-002, FL-003, FL-006, FL-007, FL-012)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 가게 이름·상호·대표자·연락처·사업자등록번호·통신판매업 신고번호(또는 면제 사유)·픽업 장소 | API-038 shop |
| 가격표(현재 버전): 크기·맛·디자인·추가 옵션의 값과 표시 방식(확정·부터·범위), 기본 디자인 여부 | API-038 priceList |
| 도안 이름과 사진 | API-038 priceList.designs |
| 오늘부터 60일의 날짜별 '받음·마감·휴무'(남은 자리 수는 없음) | API-038 days |
| 포트폴리오 사진(게시 동의한 사진만) | API-038 portfolio |
| 개인정보 처리방침 주소, 문의 주소(가게 채널) | API-038 privacyPolicyUrl·inquiryUrl |

## 액션

| 액션 | 결과 | 실패 |
| --- | --- | --- |
| 문의하기 | 가게 카카오톡 채널 상담(SCR-003)이 열림 | 카카오톡을 열 수 없는 환경(PC 브라우저 등)이면 채널 주소를 글로 보이고 복사 버튼을 둠(SPEC-011) |
| 개인정보 처리방침 | SCR-002가 열림 | 그 화면의 오류 상태(SCR-002#error) |
| 다음 달·이전 달 | 받은 60일 안에서 캘린더만 이동(다시 호출하지 않음) | 60일 밖으로는 버튼이 막힘 |
| 사진 크게 보기 | 사진 보기 창 | 사진 주소(15분 서명 주소, DEC-09)가 지났으면 SCR-001#stale의 '다시 불러오기' |

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이 상태로 오는 응답 |
| --- | --- | --- |
| SCR-001#normal | 위에서부터 가게 이름, 포트폴리오, 가격표(그룹별), 60일 캘린더('받음·마감·휴무'. 다 찬 날·사장님이 마감한 날·추가 수락한 날은 모두 '마감'), 가게 정보, 처리방침 링크. '문의하기'는 360에서 화면 아래 고정, 1280에서 오른쪽 열 위 | API-038#200:page, API-038#200:no_photos |
| SCR-001#loading | 레이아웃은 그대로 두고 데이터 자리에 회색 막대를 보임. 액션 버튼은 누를 수 없음. 사진 영역·가격표 행·캘린더 셀의 크기는 normal과 같음 | (데이터를 불러오는 동안) |
| SCR-001#empty | 포트폴리오에 올린 사진이 없음: 포트폴리오 자리에 '아직 사진이 없어요'. 가격표·캘린더·가게 정보·문의하기는 normal과 같음 | - |
| SCR-001#error | 없는 링크나 발급 전 가게(404): '찾을 수 없어요'와 '가게 주소를 다시 확인해 주세요'. 가게가 있는지는 말하지 않고, 공개 페이지라 돌아갈 목록 링크가 없음. 그 밖의 실패: '문제가 생겼어요. 다시 시도해 주세요'와 다시 시도 버튼, 추적 ID | API-038#404:not_found, API-038#default:internal |
| SCR-001#rate-limited | 같은 곳에서 1분에 60번을 넘게 엶(429): '잠시 뒤 다시 시도해 주세요'. Retry-After 초가 지나면 자동으로 다시 불러옴 | API-038#429:rate_limited |
| SCR-001#stale | 페이지를 연 지 오래되어 빈 날짜가 바뀌었을 수 있거나 사진 주소(15분)가 만료됨: 캘린더 위에 'HH:MM 기준'과 '다시 불러오기'. 빈 날짜는 문의에서 가게 규칙이 다시 판정함(SPEC-014) | - |
| permission (해당 없음) | 누구나 보는 공개 페이지(로그인 없음). 보이면 안 되는 정보(손님 이름·주문·남은 자리 수·내부 ID)는 응답에 아예 없음(G6, DEC-19) |  |

## 응답과 상태

06단계 계약(`api/openapi.yaml`)의 응답마다 화면 상태 하나입니다. 오류의 문구는 06단계 오류 코드 표의 '화면에 보이는 말'입니다.

| 응답 | 화면 상태 | 화면에 보이는 것 |
| --- | --- | --- |
| API-038#200:page | SCR-001#normal | 포트폴리오·가격표·빈 날짜·가게 신원 정보 |
| API-038#200:no_photos | SCR-001#normal | 포트폴리오 자리에 '아직 사진이 없어요' |
| API-038#404:not_found | SCR-001#error | 찾을 수 없어요 · 가게 주소를 다시 확인해 주세요(목록 링크 없음) |
| API-038#429:rate_limited | SCR-001#rate-limited | '잠시 뒤 다시 시도해 주세요' |
| API-038#default:internal | SCR-001#error | '문제가 생겼어요. 다시 시도해 주세요' |

## 케이스 유형

| 케이스 유형 | 화면에 보이는 것 |
| --- | --- |
| 대상 | 없는 링크나 발급 전 가게는 같은 '찾을 수 없어요'(SCR-001#error). 가게가 있는지 알리지 않음 |
| 상태 변화 | 다 찬 날·사장님이 마감한 날·추가 수락한 날은 모두 '마감', 휴무일은 '휴무'(SCR-001#normal). 남은 자리 수는 보이지 않음 |
| 한도 | 1분 60번을 넘으면 SCR-001#rate-limited. 남은 초가 지나면 자동으로 다시 불러옴 |
| 외부 서비스 | 카카오톡을 열 수 없으면 채널 주소를 글로 보이고 복사 버튼(문의하기의 실패) |
| 데이터 노출 | 손님 이름·주문·남은 자리 수·내부 ID 없음. 사장님 연락처와 사업자 정보만(G6) |
| 빈 응답·끊긴 응답 | 포트폴리오 사진이 없으면 SCR-001#empty |
| 화면 상태 | 상태마다 360·1280 와이어프레임(`wireframes.html#SCR-001`) |
