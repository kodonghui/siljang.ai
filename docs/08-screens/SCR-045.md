# SCR-045 후기

- 경로: `/owner/reviews`
- 접근 권한: 사장님
- 상위 화면: SCR-034 가게 설정
- 화면 레이아웃: 사장님 화면(1280 왼쪽 메뉴, 360 위쪽 막대와 메뉴 버튼)
- 플로우: 플로우 노드 없음(06단계 API-066에서 나온 화면이고, FL-012는 후기 사진을 포트폴리오 화면에서 고름)
- 관련 SPEC: SPEC-062
- API: API-066
- 와이어프레임: `wireframes.html#SCR-045`(상태 6개, 360·1280)
- 목업: [`SCR-045-360`](../../research/cake-mockup-2026-11/canvas/project/SCR-045-360.dc.html)(normal·empty·error), [`SCR-045-1280`](../../research/cake-mockup-2026-11/canvas/project/SCR-045-1280.dc.html)(normal). 캔버스의 '사장님 화면' 페이지([09단계 README](../09-mockup/README.md) 2절)

목적: 사장님이 받은 후기와 사진마다의 게시 동의를 봅니다. (플로우 노드 없음: 06단계 API-066에서 나온 화면이고, FL-012는 후기 사진을 포트폴리오 화면에서 고름)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 후기: 주문·버전·글(1,000자)·남긴 시각·사진(5장)과 사진마다 게시 동의 | API-066 items |
| 다음 페이지 | API-066 nextCursor |

## 액션

| 액션 | 결과 | 실패 |
| --- | --- | --- |
| 더 보기 | 다음 페이지를 목록 아래에 추가로 불러옴 | 실패하면 목록 끝에 '다시 시도' |
| 포트폴리오로 | 포트폴리오(SCR-044) | 그 화면의 상태 |
| 주문 보기 | 주문 상세(SCR-021) | 그 화면의 상태 |

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이 상태로 오는 응답 |
| --- | --- | --- |
| SCR-045#normal | 최근 순 후기 목록: 주문번호·남긴 시각·글·사진 썸네일. 사진마다 '게시 동의'·'동의 안 함'·'철회' 라벨. 같은 주문의 두 번째 후기는 '버전 2' | API-066#200:reviews |
| SCR-045#loading | 레이아웃은 그대로 두고 데이터 자리에 회색 막대를 보임. 액션 버튼은 누를 수 없음 | (데이터를 불러오는 동안) |
| SCR-045#empty | '아직 받은 후기가 없어요' | API-066#200:empty |
| SCR-045#error | 주소의 필터·페이지 값이 틀림(422 validation_failed): '입력한 내용을 확인해 주세요'와 '처음부터 보기'. 그 밖의 실패: '문제가 생겼어요. 다시 시도해 주세요'와 다시 시도 버튼, 추적 ID | API-066#422:validation_failed, API-066#default:internal |
| SCR-045#permission | 로그인이 없거나 만료됨(401 unauthenticated): 로그인 화면으로 이동하고, 로그인하면 이 화면으로 돌아옴('다시 로그인해 주세요'). 로그인한 사장님에게 가게가 아직 없음(404 shop_not_registered): 가게가 없으면 가게 등록(SCR-015)으로 보냄('가게를 먼저 등록해 주세요') | API-066#401:unauthenticated, API-066#404:shop_not_registered |
| SCR-045#stale | 목록은 연 시각 기준이라 그 뒤 바뀐 것이 안 보일 수 있음: 맨 위에 'HH:MM 기준'과 '새로 고침'. 다른 화면에서 처리하고 돌아오면 다시 불러옴. 손님이 동의를 철회하면 다시 불러올 때 라벨이 바뀜 | - |

## 응답과 상태

06단계 계약(`api/openapi.yaml`)의 응답마다 화면 상태 하나입니다. 오류의 문구는 06단계 오류 코드 표의 '화면에 보이는 말'입니다.

| 응답 | 화면 상태 | 화면에 보이는 것 |
| --- | --- | --- |
| API-066#200:reviews | SCR-045#normal | 후기와 사진마다 게시 동의 |
| API-066#200:empty | SCR-045#empty | '아직 받은 후기가 없어요' |
| API-066#401:unauthenticated | SCR-045#permission | '다시 로그인해 주세요' |
| API-066#404:shop_not_registered | SCR-045#permission | '가게를 먼저 등록해 주세요' |
| API-066#422:validation_failed | SCR-045#error | '입력한 내용을 확인해 주세요' |
| API-066#default:internal | SCR-045#error | '문제가 생겼어요. 다시 시도해 주세요' |

## 케이스 유형

| 케이스 유형 | 화면에 보이는 것 |
| --- | --- |
| 접근 | 로그인한 사장님의 가게만. 401은 SCR-045#permission |
| 입력 | 주소의 페이지 값이 틀리면 SCR-045#error |
| 대상 | 가게가 없으면 SCR-045#permission |
| 데이터 노출 | 후기에 손님 연락처 없음. 사진은 동의한 것만 포트폴리오 후보 |
| 빈 응답·끊긴 응답 | 후기가 없으면 SCR-045#empty |
| 화면 상태 | 상태마다 360·1280 와이어프레임(`wireframes.html#SCR-045`) |
