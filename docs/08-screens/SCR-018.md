# SCR-018 상담 대화

- 경로: `/owner/consultations/:consultationId`
- 접근 권한: 사장님
- 상위 화면: SCR-017 에스컬레이션 건
- 화면 레이아웃: 사장님 화면(1280 왼쪽 메뉴, 360 위쪽 막대와 메뉴 버튼)
- 플로우: FL-004
- 관련 SPEC: SPEC-021, SPEC-019, SPEC-065, SPEC-068
- API: API-043
- 와이어프레임: `wireframes.html#SCR-018`(상태 6개, 360·1280)
- 목업: [`SCR-018-360`](../../research/cake-mockup-2026-11/canvas/project/SCR-018-360.dc.html)(normal·empty·error), [`SCR-018-1280`](../../research/cake-mockup-2026-11/canvas/project/SCR-018-1280.dc.html)(normal). 캔버스의 '사장님 화면' 페이지([09단계 README](../09-mockup/README.md) 2절)

목적: 사장님이 에스컬레이션 건의 앞뒤 대화와 참고 사진을 봅니다. 마스킹한 전화번호·계좌번호는 이 화면에서만 원래 값으로 보입니다. (FL-004)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 상담 상태(열림·사장님 답 기다림·끊김·주문됨·끝남·지워짐)와 손님 채널 친구 여부 | API-043 status·customerChannelFriend |
| 메시지: 시각·발신자(손님·AI·서버)·종류(글·사진·카드·지원하지 않는 메시지)·글(원래 값)·사진·전달 결과(바로·콜백·다음 대화 때·실패) | API-043 items |
| 이전 페이지 | API-043 nextCursor |

## 액션

| 액션 | 결과 | 실패 |
| --- | --- | --- |
| 이전 대화 더 보기 | 이전 메시지 20개를 위에 추가로 불러옴 | 실패하면 맨 위에 '다시 시도' |
| 사진 크게 보기 | 사진 보기 창 | 사진 주소(15분)가 지났으면 SCR-018#stale의 '다시 불러오기' |

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이 상태로 오는 응답 |
| --- | --- | --- |
| SCR-018#normal | 대화를 시각 순으로: 손님 말은 왼쪽, AI·서버 안내는 오른쪽에 '손님'·'AI'·'서버 안내' 라벨과 시각. 전달 결과가 '다음 대화 때 전함'·'보내지 못함'이면 말풍선 아래 표시. 마스킹했던 번호는 원래 값으로 보이고 옆에 'AI에는 마스킹해서 보냄'. 상담 끝남(다룬 주문이 모두 끝나 닫힌 상담)도 지우기 전까지 대화가 그대로 보이고, 그 손님의 다음 말은 새 상담에 있음 | API-043#200:messages |
| SCR-018#loading | 레이아웃은 그대로 두고 데이터 자리에 회색 막대를 보임. 액션 버튼은 누를 수 없음. 말풍선 자리에 회색 막대 세 개 | (데이터를 불러오는 동안) |
| SCR-018#empty | 닫힌 지 30일이 지나고 다룬 주문이 모두 보관 기록이 되어 지운 상담(deleted): '보관 기간 30일이 지나 대화를 지웠어요'. 주문의 계약·결제 기록은 보관 기록으로 따로 남고 화면에는 보이지 않음(SPEC-065, REQ-187) | API-043#200:deleted |
| SCR-018#error | 없거나 다른 가게의 상담(404 not_found): '찾을 수 없어요'와 '할 일 목록으로' 링크(SCR-016). 다른 가게 기록이 있는지는 말하지 않음(G1). 주소의 필터·페이지 값이 틀림(422 validation_failed): '입력한 내용을 확인해 주세요'와 '처음부터 보기'. 그 밖의 실패: '문제가 생겼어요. 다시 시도해 주세요'와 다시 시도 버튼, 추적 ID | API-043#404:not_found, API-043#422:validation_failed, API-043#default:internal |
| SCR-018#permission | 로그인이 없거나 만료됨(401 unauthenticated): 로그인 화면으로 이동하고, 로그인하면 이 화면으로 돌아옴('다시 로그인해 주세요') | API-043#401:unauthenticated |
| SCR-018#stale | 연 뒤 새 메시지가 올 수 있음: 맨 아래 'HH:MM 기준'과 '새로 고침'. 사진 주소는 15분 뒤 만료돼 '다시 불러오기'를 눌러야 보임 | - |

## 응답과 상태

06단계 계약(`api/openapi.yaml`)의 응답마다 화면 상태 하나입니다. 오류의 문구는 06단계 오류 코드 표의 '화면에 보이는 말'입니다.

| 응답 | 화면 상태 | 화면에 보이는 것 |
| --- | --- | --- |
| API-043#200:messages | SCR-018#normal | 대화(마스킹 원본 값 포함)와 참고 사진 |
| API-043#200:deleted | SCR-018#empty | '보관 기간 30일이 지나 대화를 지웠어요' |
| API-043#401:unauthenticated | SCR-018#permission | '다시 로그인해 주세요' |
| API-043#404:not_found | SCR-018#error | '찾을 수 없어요' |
| API-043#422:validation_failed | SCR-018#error | '입력한 내용을 확인해 주세요' |
| API-043#default:internal | SCR-018#error | '문제가 생겼어요. 다시 시도해 주세요' |

## 케이스 유형

| 케이스 유형 | 화면에 보이는 것 |
| --- | --- |
| 접근 | 그 가게 상담만. 다른 가게 상담은 SCR-018#error(G1) |
| 입력 | 주소의 페이지 값이 틀리면 SCR-018#error |
| 대상 | 없는 상담은 SCR-018#error, 30일이 지나 지운 상담은 SCR-018#empty |
| 데이터 노출 | 마스킹한 번호의 원래 값은 이 화면에만(SPEC-021). 로그·오류 보고에는 마스킹한 대화만 |
| 빈 응답·끊긴 응답 | 지운 상담은 SCR-018#empty. 주문의 계약·결제 기록은 보관 기록으로 남음(SPEC-065) |
| 화면 상태 | 상태마다 360·1280 와이어프레임(`wireframes.html#SCR-018`) |
