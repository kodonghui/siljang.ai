# SCR-044 포트폴리오

- 경로: `/owner/portfolio`
- 접근 권한: 사장님
- 상위 화면: SCR-034 가게 설정
- 화면 레이아웃: 사장님 화면(1280 왼쪽 메뉴, 360 위쪽 막대와 메뉴 버튼)
- 플로우: FL-012
- 관련 SPEC: SPEC-063
- API: API-067, API-068, API-069
- 와이어프레임: `wireframes.html#SCR-044`(상태 8개, 360·1280)
- 목업: [`SCR-044-360`](../../research/cake-mockup-2026-11/canvas/project/SCR-044-360.dc.html)(normal·empty·error), [`SCR-044-1280`](../../research/cake-mockup-2026-11/canvas/project/SCR-044-1280.dc.html)(normal). 캔버스의 '사장님 화면' 페이지([09단계 README](../09-mockup/README.md) 2절)

목적: 사장님이 손님이 게시에 동의하고 철회하지 않은 완성 사진과 후기 사진을 골라 포트폴리오에 올리거나 내립니다. 가게가 도안으로 올린 견본 사진은 손님 사진이 아니라 여기 없고 가격표(SCR-001)에 보입니다. (FL-012)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 올린 사진(출처·올린 시각) | API-067 items |
| 올릴 수 있는 사진: 출처(완성 사진·후기 사진)·주문·그 사진의 게시 동의(동의·동의 안 함·철회) | API-067 candidates(REQ-209) |
| 올리기·내리기 결과 | API-068 outcome·item, API-069 outcome·item |

## 액션

| 액션 | 결과 | 실패 |
| --- | --- | --- |
| 올리기(그 사진에 동의하고 철회하지 않은 사진만) | '포트폴리오에 올렸어요'. 이미 올렸으면 '이미 올린 사진이에요' | 그 사이 손님이 동의를 철회함(409 photo_consent_missing)은 SCR-044#stale, 없거나 다른 가게 사진(422 validation_failed의 /photoId reference_not_found, DEC-02)은 SCR-044#error |
| 내리기 | '내렸어요. 예약 링크 페이지에서 5분 안에 사라져요' | 이미 내림(200 unchanged)은 SCR-044#done, 없는 사진(404)은 SCR-044#error |

## 케이스 유형

| 케이스 유형 | 화면에 보이는 것 |
| --- | --- |
| 접근 | 로그인한 사장님의 가게만. 401은 SCR-044#permission |
| 입력 | 요청 값이 틀리면 SCR-044#error |
| 대상 | 없는 사진·다른 가게 사진은 SCR-044#error(올리기는 422 reference_not_found, 내리기는 404. 어느 쪽도 다른 가게 사진이 있는지 말하지 않음, DEC-02), 가게가 없으면 SCR-044#permission |
| 상태 변화 | 동의 안 한 사진과 철회한 사진은 올리기 버튼이 없고 서버와 데이터베이스도 거절(SCR-044#stale, REQ-209). 다른 사진의 동의로는 올리지 못함 |
| 반복 | 올리기·내리기를 두 번 눌러도 한 번(SCR-044#done의 unchanged) |
| 동시 변경 | 그 사이 손님이 동의를 철회하면 SCR-044#stale |
| 데이터 노출 | 내린 사진은 예약 링크 페이지에서 5분 안에 사라짐(SPEC-063) |
| 빈 응답·끊긴 응답 | 올린 사진이 없으면 SCR-044#empty |
| 화면 상태 | 상태마다 360·1280 와이어프레임(`wireframes.html#SCR-044`) |
