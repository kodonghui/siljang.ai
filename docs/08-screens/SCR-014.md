# SCR-014 사장님 로그인

- 경로: `/owner/login`
- 접근 권한: 비로그인
- 상위 화면: 없음(루트)
- 화면 레이아웃: 로그인(가운데 카드)
- 플로우: FL-001
- 관련 SPEC: SPEC-001
- API: API-001
- 와이어프레임: `wireframes.html#SCR-014`(상태 4개, 360·1280)
- 목업: [`SCR-014-360`](../../research/cake-mockup-2026-11/canvas/project/SCR-014-360.dc.html)(normal·error), [`SCR-014-1280`](../../research/cake-mockup-2026-11/canvas/project/SCR-014-1280.dc.html)(normal). 캔버스의 '사장님 화면' 페이지([09단계 README](../09-mockup/README.md) 2절)

목적: 사장님이 카카오 로그인으로 들어옵니다. 가게가 없으면 가게 등록으로, 영업 신고가 보류된 가게는 영업 신고로, 그 밖에는 할 일 목록이나 로그인 전에 열던 화면으로 갑니다. (FL-001)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 로그인한 사장님(알림 채널 친구 여부)과 가게(이름·영업 신고 상태) | API-001 owner·shop |
| 로그인 뒤 갈 화면(가게 등록·영업 신고 다시 올리기·할 일 목록) | API-001 next |

## 액션

| 액션 | 결과 | 실패 |
| --- | --- | --- |
| 카카오 로그인 | 카카오 로그인 화면에 갔다가 돌아오면(/owner/login/callback) 인가 코드로 로그인하고 다음 화면으로 이동: 가게가 없으면 가게 등록(SCR-015), 보류된 가게는 영업 신고(SCR-035), 그 밖에는 할 일 목록(SCR-016)이나 로그인 전에 열던 사장님 화면 | 카카오 로그인 실패·동의 거부(401 kakao_login_failed)와 카카오 장애(503 kakao_unavailable)는 SCR-014#error, 너무 잦은 시도(429)는 SCR-014#rate-limited. 우리 쪽 기록은 남기지 않음(SPEC-001) |

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이 상태로 오는 응답 |
| --- | --- | --- |
| SCR-014#normal | 가운데 서비스 이름과 '사장님 로그인', 버튼 '카카오 로그인' 하나, 아래 '가게 사장님용'(운영자 로그인과 헷갈리지 않게). 로그인 전에 사장님 화면 주소를 열고 왔으면 '로그인하면 보던 화면으로 돌아가요' | API-001#200:new_owner, API-001#200:returning_owner, API-001#200:license_on_hold |
| SCR-014#loading | 카카오에서 돌아와 로그인을 처리하는 중(/owner/login/callback): 버튼 자리에 '로그인하고 있어요'. 버튼은 누를 수 없음 | (데이터를 불러오는 동안) |
| SCR-014#error | 카카오 로그인 실패나 동의 거부(401 kakao_login_failed), 돌아온 주소에 인가 코드가 없거나 형식이 틀림(422): 버튼 위에 '카카오 로그인을 다시 해 주세요'. 카카오 장애(503): 06단계 kakao_unavailable 문구와 다시 시도. 그 밖의 실패: '문제가 생겼어요. 다시 시도해 주세요'와 다시 시도 버튼, 추적 ID | API-001#401:kakao_login_failed, API-001#422:validation_failed, API-001#503:kakao_unavailable, API-001#default:internal |
| SCR-014#rate-limited | 같은 곳에서 로그인을 너무 자주 시도함(429 rate_limited): '잠시 뒤 다시 시도해 주세요'. Retry-After 초가 지날 때까지 버튼이 막힘 | API-001#429:rate_limited |
| empty (해당 없음) | 보일 데이터가 없는 버튼 화면 |  |
| permission (해당 없음) | 로그인 전에 여는 화면이라 권한이 필요 없음 |  |
| stale (해당 없음) | 보이는 데이터가 없어 오래될 것이 없음 |  |

## 응답과 상태

06단계 계약(`api/openapi.yaml`)의 응답마다 화면 상태 하나입니다. 오류의 문구는 06단계 오류 코드 표의 '화면에 보이는 말'입니다.

| 응답 | 화면 상태 | 화면에 보이는 것 |
| --- | --- | --- |
| API-001#200:new_owner | SCR-014#normal | 가게 등록(SCR-015)으로 이동 |
| API-001#200:returning_owner | SCR-014#normal | 할 일 목록(SCR-016), 로그인 전에 열던 주소가 있으면 그 화면으로 이동 |
| API-001#200:license_on_hold | SCR-014#normal | 영업 신고(SCR-035)로 이동해 보류 사유와 '신고증 다시 올리기'를 보임 |
| API-001#401:kakao_login_failed | SCR-014#error | '카카오 로그인을 다시 해 주세요' |
| API-001#422:validation_failed | SCR-014#error | 카카오 로그인을 다시 해 주세요(인가 코드가 없거나 형식이 틀림) |
| API-001#429:rate_limited | SCR-014#rate-limited | '잠시 뒤 다시 시도해 주세요' |
| API-001#503:kakao_unavailable | SCR-014#error | '카카오에 연결하지 못했어요. 잠시 뒤 다시 해 주세요' |
| API-001#default:internal | SCR-014#error | '문제가 생겼어요. 다시 시도해 주세요' |

## 케이스 유형

| 케이스 유형 | 화면에 보이는 것 |
| --- | --- |
| 접근 | 카카오 로그인 실패·동의 거부는 SCR-014#error. 로그인하지 않고 사장님 화면 주소를 열면 이 화면으로 오고, 로그인 뒤 그 주소로 돌아감(SPEC-001) |
| 입력 | 돌아온 주소에 인가 코드가 없거나 형식이 틀리면 SCR-014#error의 '카카오 로그인을 다시 해 주세요' |
| 상태 변화 | 영업 신고가 보류된 가게의 사장님도 들어와 영업 신고(SCR-035)에서 신고증을 다시 올림 |
| 외부 서비스 | 카카오 장애는 SCR-014#error. 실패하면 우리 쪽 기록을 남기지 않음 |
| 한도 | 너무 잦은 시도는 SCR-014#rate-limited |
| 데이터 노출 | 카카오 토큰은 화면·주소·로그에 없음(REQ-135) |
| 화면 상태 | 상태마다 360·1280 와이어프레임(`wireframes.html#SCR-014`) |

## 긴 글과 좁은 화면
