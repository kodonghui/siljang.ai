# SCR-012 후기 남기기

- 경로: `kakao:shop/block/review`
- 접근 권한: 주문한 손님
- 상위 화면: SCR-003 가게 채널 상담
- 화면 레이아웃: 카카오톡 채널 대화 화면(1280은 PC 카카오톡 창)
- 플로우: FL-012
- 관련 SPEC: SPEC-062, SPEC-061, SPEC-019
- API: API-072
- 와이어프레임: `wireframes.html#SCR-012`(상태 4개, 360·1280)
- 목업: [`SCR-012-360`](../../research/cake-mockup-2026-11/canvas/project/SCR-012-360.dc.html)(normal·error), [`SCR-012-1280`](../../research/cake-mockup-2026-11/canvas/project/SCR-012-1280.dc.html)(normal). 캔버스의 '손님 화면' 페이지([09단계 README](../09-mockup/README.md) 2절)

목적: 받은 주문의 손님이 후기 부탁의 버튼이나 채널의 '후기' 블록에서 글과 사진(5장까지)을 남기고 사진 게시 동의를 고릅니다. 기본은 동의 안 함입니다. (FL-012)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 후기 글(1~1,000자) | API-072 params.review_text |
| 사진(보안 이미지 플러그인, 5장까지) | API-072 params.review_photos |
| 사진 게시 동의(기본 '동의 안 함', 후기 하나에 한 번 묻고 사진마다 남김) | API-072 params.photo_consent(DEC-18) |
| 주문번호 | API-072 clientExtra.orderNo |

## 액션

| 액션 | 결과 | 실패 |
| --- | --- | --- |
| 글 쓰기·사진 고르기(블록이 차례로 물음) | 블록이 다음 질문으로 감 | 1,000자·5장을 넘으면 SCR-012#error의 문구(review_invalid) |
| 게시 동의 고르기('동의'·'동의 안 함') | 고른 답을 사진마다 같게 남김 | 고르지 않으면 '동의 안 함' |
| 보내기 | 후기를 남김. 같은 주문의 두 번째 후기는 새 버전(SPEC-062) | 받은 주문이 아니면 SCR-012#permission, 사진 내려받기 실패는 SCR-012#error |

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이 상태로 오는 응답 |
| --- | --- | --- |
| SCR-012#normal | 오픈빌더 '후기' 블록: '케이크는 어떠셨어요?' 글 입력, 사진 고르기(보안 이미지 플러그인, 5장), '사진을 가게 포트폴리오에 올려도 될까요?' 바로가기 '동의'·'동의 안 함'(기본 동의 안 함), 보내기 | - |
| SCR-012#done | '후기를 남겨 주셔서 고마워요'. 같은 요청이 다시 와도 같은 말(duplicate) | API-072#200:review_saved, API-072#200:duplicate |
| SCR-012#permission | 받은 주문이 아니거나 그 주문을 요청한 사용자가 아님(review_not_allowed): '받으신 주문에만 후기를 남길 수 있어요'. 채널 연결이 끊긴 가게(not_accepting): '아직 상담을 받지 않아요…' | API-072#200:review_not_allowed, API-072#200:not_accepting |
| SCR-012#error | 글이 1~1,000자 밖이거나 사진이 5장을 넘음(review_invalid): '후기는 1,000자, 사진은 5장까지 남길 수 있어요'. 사진 내려받기가 두 번 실패(photo_download_failed): '사진을 받지 못했어요. 다시 보내 주세요'. 서버 오류는 '잠시 뒤 다시 말씀해 주세요'. 스킬 401·422·default: 카카오톡이 자기 오류 말을 보임(우리 문구 없음, DEC-07). 서버 로그에 추적 ID | API-072#200:review_invalid, API-072#200:photo_download_failed, API-072#200:server_error, API-072#401:skill_key_invalid, API-072#422:validation_failed, API-072#default:internal |
| loading (해당 없음) | 블록 응답을 기다리는 동안 카카오톡이 자기 표시를 함 |  |
| empty (해당 없음) | 후기 블록은 손님이 쓰는 입력 영역이라 보일 데이터가 없음 |  |
| stale (해당 없음) | 지난 후기를 보여 주지 않음. 같은 주문의 두 번째 후기는 새 버전으로 남음 |  |

## 응답과 상태

06단계 계약(`api/openapi.yaml`)의 응답마다 화면 상태 하나입니다. 오류의 문구는 06단계 오류 코드 표의 '화면에 보이는 말'입니다.

| 응답 | 화면 상태 | 화면에 보이는 것 |
| --- | --- | --- |
| API-072#200:review_saved | SCR-012#done | '후기를 남겨 주셔서 고마워요' |
| API-072#200:review_not_allowed | SCR-012#permission | '받으신 주문에만 후기를 남길 수 있어요' |
| API-072#200:review_invalid | SCR-012#error | '후기는 1,000자, 사진은 5장까지 남길 수 있어요' |
| API-072#200:photo_download_failed | SCR-012#error | '사진을 받지 못했어요. 다시 보내 주세요' |
| API-072#200:duplicate | SCR-012#done | (처음 결과와 같은 말) |
| API-072#200:block_verified | 나오지 않음 | 채널 연결 확인의 '시험: 후기' 버튼 결과라 후기 남기기에서는 나오지 않음(SCR-003#link-test) |
| API-072#200:channel_linked | 나오지 않음 | 채널 연결 확인의 '시험: 후기' 버튼 결과라 후기 남기기에서는 나오지 않음(SCR-003#link-test) |
| API-072#200:not_accepting | SCR-012#permission | '아직 상담을 받지 않아요. 가게로 연락해 주세요: {가게 연락처}' |
| API-072#200:server_error | SCR-012#error | '잠시 뒤 다시 말씀해 주세요' |
| API-072#401:skill_key_invalid | SCR-012#error | (우리 문구 없음. 카카오톡이 자기 오류 말을 보임) |
| API-072#422:validation_failed | SCR-012#error | (우리 문구 없음. 카카오톡이 자기 오류 말을 보임) |
| API-072#default:internal | SCR-012#error | (우리 문구 없음. 카카오톡이 자기 오류 말을 보임) |

## 케이스 유형

| 케이스 유형 | 화면에 보이는 것 |
| --- | --- |
| 접근 | 그 주문을 요청한 사용자의 받은 주문만(SCR-012#permission) |
| 입력 | 글 1~1,000자·사진 5장 밖은 SCR-012#error |
| 대상 | 받지 않은 주문은 SCR-012#permission |
| 반복 | 같은 요청은 처음 결과(SCR-012#done). 같은 주문의 두 번째 후기는 새 버전 |
| 한도 | 글 1,000자·사진 5장(SCR-012#error) |
| 외부 서비스 | 카카오 사진 주소에서 두 번 못 받으면 SCR-012#error의 '사진을 받지 못했어요' |
| 데이터 노출 | 결과에 오류 내용 없음. 사진은 동의한 것만 포트폴리오 후보가 됨 |
| 화면 상태 | 상태마다 360·1280 와이어프레임(`wireframes.html#SCR-012`) |

## 긴 글과 좁은 화면

| 항목 | 한도 | 화면에서 |
| --- | --- | --- |
| 카드 설명 | 카드의 제목과 설명을 합쳐 400자, 한 응답의 출력 3개(카카오 스킬 응답 형식 문서, 2026-11-13 읽음) | 넘는 내용은 카드 앞의 글 말풍선(1,000자)으로 나눔. 버튼 이름은 14자 안 |
| 좁은 화면 | 360 | 말풍선은 카카오톡이 줄바꿈해 렌더링함. 1280 프레임은 PC 카카오톡 대화창(너비 약 480px로 가정) |
| 후기 글 | 1,000자 | 카카오톡 입력창 그대로. 넘으면 SCR-012#error |
