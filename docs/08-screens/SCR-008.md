# SCR-008 변경 요청 카드

- 경로: `kakao:shop/card/change_request`
- 접근 권한: 주문한 손님
- 상위 화면: SCR-007 내 주문 보기
- 화면 레이아웃: 카카오톡 채널 대화 화면(1280은 PC 카카오톡 창)
- 플로우: FL-008
- 관련 SPEC: SPEC-041, SPEC-069
- API: API-071
- 와이어프레임: `wireframes.html#SCR-008`(상태 6개, 360·1280)

목적: 주문한 손님이 바꾸려는 디자인·문구·날짜·시간과 지금 주문 버전을 확인하고 변경 요청 버튼을 누릅니다. (FL-008)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 바꾸려는 내용(이전 → 새) | API-071 카드(처음 카드는 SCR-003의 API-070 card_shown) |
| 지금 주문 버전과 변경 마감 | API-071 카드 |
| 새 날짜가 휴무·마감된 날이면 '받을지 사장님이 정해요' | API-071 카드(SPEC-041) |

## 액션

| 액션 | 결과 | 실패 |
| --- | --- | --- |
| 변경 요청 | 변경 요청을 남기고 사장님께 알림(SPEC-041) | 결제 전 주문·열린 변경 요청이 있음·변경 마감 지남은 SCR-008#stale, 버전이 바뀌었으면 SCR-008#stale, 30분이 지났으면 SCR-008#expired |
| 안 할래요 | 아무것도 남기지 않고 '알겠어요. 더 궁금한 것이 있으면 말씀해 주세요' | 서버 오류면 SCR-008#error |

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이 상태로 오는 응답 |
| --- | --- | --- |
| SCR-008#normal | 카드 하나: '변경 요청', 주문번호·지금 버전, 바꾸려는 항목마다 '이전 → 새', 새 날짜가 휴무·마감이면 '받을지 사장님이 정해요', 'HH:MM까지 눌러 주세요', 버튼 '변경 요청'·'안 할래요' | - |
| SCR-008#done | '변경을 요청했어요. 사장님이 보고 알려 드려요'. 같은 카드를 다시 누르면 같은 말(card_used) | API-071#200:change_requested, API-071#200:declined, API-071#200:card_used |
| SCR-008#stale | 카드의 버전이 지금 주문 버전과 다름(card_stale, REQ-133): '내용이 바뀌었어요…'와 새 카드. 지금 받을 수 없음(not_allowed_now): 결제 전 주문은 '지금은 할 수 없어요: 결제 전 주문이에요. 주문 요청을 취소하고 다시 요청할 수 있어요', 열린 변경 요청이 있으면 '… 앞의 변경 요청을 사장님이 보고 있어요' | API-071#200:card_stale, API-071#200:not_allowed_now |
| SCR-008#expired | 보낸 지 30분이 지난 카드를 누름(card_expired): '시간이 지나 새 카드를 보내 드려요'와 지금 값으로 만든 새 카드. 아무것도 남지 않음 | API-071#200:card_expired |
| SCR-008#permission | 카드를 받은 사용자가 아님(card_not_yours): '이 버튼은 카드를 받은 분만 누를 수 있어요'. 아무것도 남지 않음. 그 사이 채널 연결이 끊긴 가게(not_accepting): '아직 상담을 받지 않아요. 가게로 연락해 주세요: {가게 연락처}' | API-071#200:card_not_yours, API-071#200:not_accepting |
| SCR-008#error | 쓰기 하나가 실패해 하나도 남기지 않음(retry_needed): '다시 눌러 주세요'. 서버 오류(server_error): '잠시 뒤 다시 말씀해 주세요'. 스킬 키가 틀리거나 형식이 아니거나 예상하지 못한 실패(401·422·default): 카카오톡이 자기 오류 말을 보임(우리 문구 없음, DEC-07). 서버 로그에 추적 ID | API-071#200:retry_needed, API-071#200:server_error, API-071#401:skill_key_invalid, API-071#422:validation_failed, API-071#default:internal |
| loading (해당 없음) | 버튼을 누른 뒤 답이 올 때까지는 카카오톡이 자기 표시를 함. 우리가 그릴 것이 없음 |  |
| empty (해당 없음) | 카드는 서버가 저장된 값이 있을 때만 만들어 보임(SPEC-069). 빈 카드는 없음 |  |

## 응답과 상태

06단계 계약(`api/openapi.yaml`)의 응답마다 화면 상태 하나입니다. 오류의 문구는 06단계 오류 코드 표의 '화면에 보이는 말'입니다.

| 응답 | 화면 상태 | 화면에 보이는 것 |
| --- | --- | --- |
| API-071#200:order_requested | 나오지 않음 | 이 카드에서는 나오지 않음(SCR-004 주문 요청 카드의 결과) |
| API-071#200:payment_claimed | 나오지 않음 | 이 카드에서는 나오지 않음(SCR-006 결제 확인 요청 카드의 결과) |
| API-071#200:change_requested | SCR-008#done | '변경을 요청했어요. 사장님이 보고 알려 드려요' |
| API-071#200:order_cancelled | 나오지 않음 | 이 카드에서는 나오지 않음(SCR-009 취소 카드의 결과) |
| API-071#200:issue_reported | 나오지 않음 | 이 카드에서는 나오지 않음(SCR-010 문제 신고 카드의 결과) |
| API-071#200:consent_withdrawn | 나오지 않음 | 이 카드에서는 나오지 않음(SCR-013 사진 게시 동의 철회 카드의 결과) |
| API-071#200:declined | SCR-008#done | '알겠어요. 더 궁금한 것이 있으면 말씀해 주세요' |
| API-071#200:card_stale | SCR-008#stale | 내용이 바뀌었어요. 새 카드를 확인해 주세요 + 새 카드 |
| API-071#200:card_expired | SCR-008#expired | 시간이 지나 새 카드를 보내 드려요 + 새 카드 |
| API-071#200:card_not_yours | SCR-008#permission | '이 버튼은 카드를 받은 분만 누를 수 있어요' |
| API-071#200:card_used | SCR-008#done | (처음 결과와 같은 말) |
| API-071#200:day_full | 나오지 않음 | 주문 요청 카드(SCR-004)에서만 나옴 |
| API-071#200:retry_needed | SCR-008#error | '다시 눌러 주세요' |
| API-071#200:not_allowed_now | SCR-008#stale | '지금은 할 수 없어요: {지금 상태}' |
| API-071#200:not_accepting | SCR-008#permission | '아직 상담을 받지 않아요. 가게로 연락해 주세요: {가게 연락처}' |
| API-071#200:server_error | SCR-008#error | '잠시 뒤 다시 말씀해 주세요' |
| API-071#401:skill_key_invalid | SCR-008#error | (우리 문구 없음. 카카오톡이 자기 오류 말을 보임) |
| API-071#422:validation_failed | SCR-008#error | (우리 문구 없음. 카카오톡이 자기 오류 말을 보임) |
| API-071#default:internal | SCR-008#error | (우리 문구 없음. 카카오톡이 자기 오류 말을 보임) |

## 케이스 유형

| 케이스 유형 | 화면에 보이는 것 |
| --- | --- |
| 접근 | 카드를 받은 같은 카카오 사용자만 누름. 다른 사람은 SCR-008#permission, 스킬 키가 틀리면 SCR-008#error |
| 입력 | 카드 값은 서버 기록에서만 오고 손님 말로 바꿀 수 없음. 스킬 요청 형식이 아니면 SCR-008#error |
| 대상 | 지금 상태에서 받을 수 없는 명령은 '지금은 할 수 없어요: {지금 상태}'(SCR-008#stale) |
| 상태 변화 | 결제 전 주문(R16)·열린 변경 요청·버전이 바뀐 카드는 SCR-008#stale, 30분이 지난 카드는 SCR-008#expired |
| 반복 | 같은 카드를 다시 누르면 처음 결과를 다시 보냄(SCR-008#done, card_used). 명령은 한 번 |
| 동시 변경 | 카드를 보낸 뒤 다른 쓰기가 먼저 이기면 SCR-008#stale |
| 외부 서비스 | 트랜잭션의 쓰기 하나가 실패하면 하나도 남기지 않고 '다시 눌러 주세요'(SCR-008#error) |
| 데이터 노출 | 카드와 결과에 다른 손님 정보·내부 ID(주문번호 밖)·오류 내용 없음(G6). 서버 오류도 '잠시 뒤 다시 말씀해 주세요'만 |
| AI 답 | AI는 카드를 제안만 하고 카드의 값(금액·버전·환불)은 서버 기록에서 만듦(SPEC-069). AI 말로 카드 값을 바꿀 수 없음 |
| 화면 상태 | 상태마다 360·1280 와이어프레임(`wireframes.html#SCR-008`) |
