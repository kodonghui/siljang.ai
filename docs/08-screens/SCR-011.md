# SCR-011 손님 알림

- 경로: `kakao:shop/notice`
- 접근 권한: 손님
- 상위 화면: SCR-003 가게 채널 상담
- 화면 레이아웃: 카카오톡 채널 대화 화면(1280은 PC 카카오톡 창)
- 플로우: FL-004, FL-005, FL-006, FL-007, FL-008, FL-009, FL-010, FL-011, FL-012
- 관련 SPEC: SPEC-066, SPEC-023, SPEC-024, SPEC-036, SPEC-039, SPEC-044, SPEC-045, SPEC-047, SPEC-052, SPEC-053, SPEC-059, SPEC-061
- API: API-073
- 와이어프레임: `wireframes.html#SCR-011`(상태 5개, 360·1280)
- 목업: [`SCR-011-360`](../../research/cake-mockup-2026-11/canvas/project/SCR-011-360.dc.html)(normal·photo-consent·deferred·error), [`SCR-011-1280`](../../research/cake-mockup-2026-11/canvas/project/SCR-011-1280.dc.html)(normal). 캔버스의 '손님 화면' 페이지([09단계 README](../09-mockup/README.md) 2절)

목적: 손님이 서비스가 먼저 보내는 안내(주문 확정·전날·완성 사진·지연·답 없어 닫힘·에스컬레이션 건의 답·결과·후기 부탁)를 가게 채널에서 받고, 완성 사진 안내에서는 그 사진의 게시 동의를 답합니다. (FL-004, FL-005, FL-006, FL-007, FL-008, FL-009, FL-010, FL-011, FL-012)

## 케이스 유형

| 케이스 유형 | 화면에 보이는 것 |
| --- | --- |
| 접근 | 안내 스킬은 그 가게의 안내만 보임(G1). 스킬 키가 틀리면 카카오가 보내지 않음(SCR-011#error) |

| 반복 | 같은 주문·같은 이벤트의 안내는 한 번(REQ-154). 같은 기다림의 지연 안내와 답 없어 닫힘 안내는 각각 한 번(SPEC-024). 안내 스킬이 같은 안내 키로 다시 불려도 같은 글. 같은 사진 게시 동의 카드를 두 번 누르면 처음 답(SCR-011#photo-consent) |

| 외부 서비스 | 카카오가 받지 않거나 발송 결과가 스킬·카카오 오류면 1분·5분·30분 뒤 다시, 그래도 안 되면 SCR-011#deferred(G4). 먼저 보내기가 안 되는 가게는 처음부터 SCR-011#deferred(REQ-181) |
