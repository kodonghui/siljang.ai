# SCR-011 손님 알림

- 경로: `kakao:shop/notice`
- 접근 권한: 손님
- 상위 화면: SCR-003 가게 채널 상담
- 화면 레이아웃: 카카오톡 채널 대화 화면(1280은 PC 카카오톡 창)
- 플로우: FL-004, FL-005, FL-006, FL-007, FL-008, FL-009, FL-010, FL-011, FL-012
- 관련 SPEC: SPEC-066, SPEC-023, SPEC-024, SPEC-036, SPEC-039, SPEC-044, SPEC-045, SPEC-047, SPEC-052, SPEC-053, SPEC-059, SPEC-061
- API: 없음(서버가 보내는 안내만 보임)
- 와이어프레임: `wireframes.html#SCR-011`(상태 4개, 360·1280)

목적: 손님이 서비스가 먼저 보내는 안내(주문 확정·전날·완성 사진·지연·에스컬레이션 건의 답·결과·후기 부탁)를 가게 채널에서 받습니다. (FL-004, FL-005, FL-006, FL-007, FL-008, FL-009, FL-010, FL-011, FL-012)

## 데이터

| 데이터 | 출처 |
| --- | --- |
| 주문 확정 안내: 주문 내용·픽업 일시·취소·환불 규정 | 서버 안내 SPEC-036, SPEC-066 |
| 전날 안내: 픽업 일시·가게 위치·연락처(위치가 비었으면 연락처만, DEC-13). 가게가 정한 시각(08:00~20:50) | 서버 안내 SPEC-052 |
| 완성 사진: 사진과 '바꾸고 싶으시면 말씀해 주세요' | 서버 안내 SPEC-053 |
| 지연 안내: '사장님 확인이 늦어지고 있어요. 확인되면 바로 알려 드릴게요' | 서버 안내 SPEC-024 |
| 에스컬레이션 건의 답: 사장님이 쓴 답 그대로(AI가 고치지 않음) | 서버 안내 SPEC-023 |
| 결과 안내: 맞춤 주문 거절·금액이 다름('보내신 금액이 안내와 달라 사장님이 연락드릴게요', 금액은 적지 않음)·취소·변경 결과·환불(금액과 받는 방법)·보상 | 서버 안내 SPEC-031, SPEC-035, SPEC-039, SPEC-042, SPEC-044, SPEC-045, SPEC-047, SPEC-048, SPEC-059 |
| 후기 부탁: 인도한 다음 날 가게가 정한 시각, '후기 남기기' 버튼 | 서버 안내 SPEC-061 |

## 액션

| 액션 | 결과 | 실패 |
| --- | --- | --- |
| 후기 남기기(후기 부탁의 버튼) | 후기 남기기(SCR-012)가 열림 | 그 화면의 상태 |
| 완성 사진을 보고 답하기 | 상담으로 이어져 바꾸고 싶다면 변경 요청(SPEC-041), 주문과 다르면 에스컬레이션 건(R20) | 상담의 상태(SCR-003) |

## 상태

| 상태 | 사용자가 보는 것과 할 수 있는 것 | 이 상태로 오는 응답 |
| --- | --- | --- |
| SCR-011#normal | 말풍선 하나(필요하면 사진·버튼). 안내마다 서버의 정해진 템플릿이고 AI가 쓰지 않으며 광고가 없음. 정해진 시각 안내(전날·후기)는 08:00~20:50에만 | - |
| SCR-011#deferred | 손님이 채널 친구가 아님: 이벤트마다 '못 보냄'으로 두었다가 손님이 다음에 말을 걸면 그 답보다 먼저 이 안내들이 감(일어난 순서로). 사장님 화면에는 '다음 대화 때 전함'(SCR-017 등) | - |
| SCR-011#stale | 보내기 전에 그 이벤트가 의미 없어지면 보내지 않음(전날 안내 전에 취소·날짜 변경, 후기 부탁 전에 문제 신고). 이미 보낸 안내는 대화에 남고 뒤의 안내가 바뀐 상태를 알림 | - |
| SCR-011#error | 카카오 보내기 실패: 1분·5분·30분 뒤 다시 보내고 그래도 안 되면 다음 대화 때 먼저 전함(G4). 손님에게 오류는 보이지 않음 | - |
| loading (해당 없음) | 서버가 먼저 보내는 말풍선이라 불러오는 동안이 없음 |  |
| empty (해당 없음) | 보낼 이벤트가 있을 때만 생김 |  |
| permission (해당 없음) | 카카오톡 1:1 대화라 그 손님에게만 보임. 안내에 다른 손님 정보가 없음 |  |

## 케이스 유형

| 케이스 유형 | 화면에 보이는 것 |
| --- | --- |
| 상태 변화 | 보내기 전에 의미 없어진 안내는 보내지 않음(SCR-011#stale) |
| 반복 | 같은 주문·같은 이벤트의 안내는 한 번(REQ-154) |
| 외부 서비스 | 보내기 실패는 1분·5분·30분 뒤 다시, 그래도 안 되면 SCR-011#deferred(G4) |
| 데이터 노출 | 다른 손님 정보·내부 ID 없음. 금액 불일치 안내에는 들어온 금액을 적지 않음(SPEC-035). 광고 0(SPEC-066) |
| 빈 응답·끊긴 응답 | 보낼 이벤트가 없으면 아무것도 가지 않음 |
| AI 답 | 안내 글은 서버의 정해진 템플릿이고 AI가 쓰지 않음(SPEC-066). 사장님 답은 고치지 않고 그대로(SPEC-023) |
| 화면 상태 | 상태마다 360·1280 와이어프레임(`wireframes.html#SCR-011`) |
