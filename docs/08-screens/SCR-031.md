# SCR-031 픽업 목록

- 경로: `/owner/pickups`
- 접근 권한: 사장님
- 상위 화면: SCR-014 사장님 로그인
- 화면 레이아웃: 사장님 화면(1280 왼쪽 메뉴, 360 위쪽 막대와 메뉴 버튼)
- 플로우: FL-010
- 관련 SPEC: SPEC-054, SPEC-055
- API: API-051, API-054, API-055, API-056
- 와이어프레임: `wireframes.html#SCR-031`(상태 10개, 360·1280)
- 목업: [`SCR-031-360`](../../research/cake-mockup-2026-11/canvas/project/SCR-031-360.dc.html)(normal·empty·error·confirm), [`SCR-031-1280`](../../research/cake-mockup-2026-11/canvas/project/SCR-031-1280.dc.html)(normal). 캔버스의 '사장님 화면' 페이지([09단계 README](../09-mockup/README.md) 2절)

목적: 사장님이 오늘 받으러 올 주문의 시각·퀵 여부를 보고 인도(픽업 완료·퀵으로 보냄)를 남기고, 픽업 일시가 지나도 오지 않은 주문은 미수령과 폐기를 남깁니다. (FL-010)

## 액션

| 액션 | 결과 | 실패 |
| --- | --- | --- |
| 픽업 완료·퀵으로 보냄 | 인도 시각을 남기고 받은 주문으로 둠: '인도를 남겼어요'. 장부의 그 주문 행에 적음 | 픽업 날짜 전이면 SCR-031#confirm, 확정되지 않은 주문·폐기한 주문(409 invalid_state)·본 뒤 바뀜은 SCR-031#stale, 이미 인도함(already_decided, 200 unchanged)은 SCR-031#done |
| 미수령 | '미수령을 남겼어요'. 늦게라도 오면 인도할 수 있음 | 픽업 일시 전(409 invalid_state)은 SCR-031#stale |
| 폐기 | 미수령 주문에 '폐기를 남겼어요'와 폐기 시각. 폐기한 주문은 인도할 수 없음 | SCR-031#stale |
| 날짜 바꾸기 | 그날 픽업 목록 | 날짜 형식이 틀리면(422) SCR-031#error에서 오늘로 |

## 케이스 유형

| 케이스 유형 | 화면에 보이는 것 |
| --- | --- |
| 접근 | 그 가게 주문만(SPEC-068). 401은 SCR-031#permission |
| 입력 | 날짜 형식이 틀리면 SCR-031#error |
| 대상 | 없는 주문은 SCR-031#error, 가게가 없으면 SCR-031#permission |
| 상태 변화 | 확정되지 않은 주문·폐기한 주문은 인도 불가, 픽업 일시 전 미수령 불가(SCR-031#stale). 픽업 날짜 전 인도는 SCR-031#confirm |
| 반복 | 같은 인도를 두 번 눌러도 한 번(SCR-031#done) |
| 동시 변경 | 본 뒤 바뀌면 SCR-031#stale |
| 데이터 노출 | 목록에는 시각·주문번호·퀵 여부만. 손님 연락처는 주문 상세에서 |
| 빈 응답·끊긴 응답 | 그날 픽업이 없으면 SCR-031#empty |
| 화면 상태 | 상태마다 360·1280 와이어프레임(`wireframes.html#SCR-031`) |
