# 수제케이크 주문제작: 사용자 흐름

상태: 초안(2026-11-11). 흐름 14개(FL-001~FL-014)를 그렸고, 03단계 확인 지점(흐름마다 주 경로와 주요 실패 길 보기)을 여쭙는 중입니다. 흐름을 그리다 찾은 새 요구사항 후보 7개(3절)와 Claude가 정한 읽은 방식 22개(4절)를 함께 여쭙니다.

이 폴더는 CORTHEX 03단계(사용자 흐름)의 원본입니다(`truth: source`). 흐름 하나가 파일 하나이고, 파일마다 Mermaid 그림이 하나 있습니다. 사람이 보고 댓글을 다는 곳은 Notion의 흐름 표(한 줄에 흐름 하나, 줄마다 같은 그림)이고, 둘이 다르면 이 폴더가 맞습니다. 말은 01단계 [domain.md](../01-domain/domain.md)의 용어(TERM-001~074)를 그대로 씁니다.

## 0. 이 단계

### 0-1. 입력

- 요구사항 1판: [requirements.md](../02-prd/requirements.md)의 REQ-001~REQ-150(main 5d2908b, 2026-11-11 22:24 판 확정). 필수 107, 권장 41, 선택 2.
- 도메인: [domain.md](../01-domain/domain.md)의 CTX-001~009, TERM-001~074, 2-2의 흐름 A~I, 5-1의 정책.
- 03단계 계약: 흐름마다 파일 하나와 Mermaid 그림 하나를 두고, 걸음마다 그 걸음이 채우는 REQ 번호를 적습니다. 확인 지점은 흐름마다 주 경로와 주요 실패 길을 보는 것입니다.

### 0-2. 흐름을 나눈 방식

- 사람이 이루려는 일 하나가 흐름 하나입니다. 손님의 일 8개(FL-003, FL-005~FL-009, FL-011, FL-012), 사장님의 일 3개(FL-001, FL-002, FL-010), 우리 서비스가 저절로 하는 일 3개(FL-004, FL-013, FL-014)입니다.
- FL-004는 손님이 말할 때마다 지나는 길입니다. 성능·보안·개인정보 요구사항이 여기에 걸립니다.
- 01단계 흐름과의 관계: A 가게 준비 → FL-001·FL-002, B 상담·견적 → FL-003~FL-005, C 날짜·수량 마감 → FL-006·FL-007(자리), D 주문 요청·확정 → FL-006·FL-007, E 변경 → FL-008, F 취소·환불 → FL-009, G 제작·전달 → FL-010, H 후기·포트폴리오 → FL-012·FL-014, I 문제 신고·보상 → FL-011. 장부 연결(CTX-009)은 FL-013입니다.

### 0-3. 그림 읽는 법

| 표시 | 뜻 |

| 파란 상자 | 손님이 하는 일과 손님이 고르는 갈림길 |
| 보라 상자 | AI 상담이 하는 일 |

| 점선 화살표 | 시간이 지나 일어나는 일(결제 기한 지남, 말이 없음 등)과 되돌아가는 길 |
