A37: 가게 행 잠금 뒤 현재 신원/요청/계좌를 같이 대조합니다. 전용 함수는 살아 있는 운영자/세션을 다시 확인하고 검색 경로를pg_catalog로 고정하며 공개 실행을 막습니다. 반영 때 현재 신원이 요청 때 값과 다르면 저장하지 않습니다. 사장님 설정/임의 SQL로 신원·판정을 직접 바꾸는 일반 권한은 주지 않습니다.

G1: 새 사장님/운영자 두 쓰기 경로를 교차 가게 목록에 넣었습니다. 사장님의 본문 가게 ID는422, 쿼리의 다른/없는/틀린 ID는 자기 가게만 보여 주며 다른 가게 전체 모습은 그대로입니다. 사장님은 운영자 판정에401입니다. 실제 운영자는 선택한 요청의 데이터베이스 가게만 열고 없는/틀린 요청은404입니다. 전체 목록은 진짜 운영자 범위만, 상세 범위는 다른 가게를 열거나 목록을 열 수 없습니다. 정확한 목록3개/가게 해석2개 SQL만 정적 검사에 허용합니다.
