## 배포 설정과 직접 확인

- PUBLIC_APP_ORIGIN: 승인된 무료 운영/스테이징의 HTTPS 원점입니다. 경로·사용자 정보·질의·프래그먼트가 있는 값은 받지 않습니다.
- PRIVACY_TRANSFER_SETTINGS: 배열이며 각 행은 provider,recipient,country,whenAndHow,purposeAndRetention,howToRefuse 여섯 필드입니다. provider는 anthropic/openai/supabase/cloudflare 중 하나이고 선택한 AI_PROVIDER와 서버 회사 두 곳이 모두 필요합니다. 실제 받는 자/나라/방법/기간/거부 절차만 넣습니다. 개인별 자료나 비밀 값은 넣지 않습니다.
- 기존 서버 역할에 tools/staging-login-callback-grants.sql의 TASK-044 두 문장을 적용합니다. 기존 처리방침 본문 UPDATE/DELETE와 영업 판정 UPDATE는 늘리지 않습니다.
