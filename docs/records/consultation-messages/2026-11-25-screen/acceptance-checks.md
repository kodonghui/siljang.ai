- 상담ID/가게가 바뀌거나 세션을 확인하면 이전 글/사진을 즉시 가리고 진행 중 읽기를 취소합니다. 원래 값은 응답을 표시하는 메모리에만 둡니다. 서버의 가게 조건/접속기록은 TASK077의 구현을 사용하며 실제 권한 확인은 별도입니다.
