## 본문과 국외 이전

서버 본문 생성기는 일반 문자열을 문단으로 구분합니다. 본문을 HTML/마크다운으로 실행하거나 법률 문구를 다시 쓰지 않고 React 텍스트로 보입니다. 문단 안 줄바꿈을 보존합니다. 별도 국외 이전 표의 다섯 개념은 받는 자·개인정보 항목·국가/시기/방법·목적/기간·거부 방법입니다. 360 카드에서는 항목 이름과 값을 함께 보입니다. 같은 받는 자가 반복되어도 행을 지우지 않습니다. 최대 본문10만자·이전20행을 화면에서 자르지 않는 시험이 있습니다.

목차는 본문/국외 이전 제목으로 초점과 스크롤을 옮기고 API를 다시 읽지 않습니다. 예약 링크 페이지로의 주소는 `/s/:slug`입니다. SCR-001 전체 화면은 TASK-061이 남아 있어 실제 상위 화면 왕복 플로우는 아직 확인하지 않았습니다.
