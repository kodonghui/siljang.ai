- 1번: A33의 대상은 실제 가게 ID, 이벤트는 판정 상태/운영자/시각/이유의 지문으로 지었습니다. 같은 이유의 보류는unchanged입니다. 새 이유는 이전 보류를 대체하고, 확인됨은 보류를 해소하므로 이전 할 일을 닫습니다.1-9의 사장님 처리에 해당하는 계좌 재제출도 같은 정리를 합니다. pending 알림의 다음 시각만 비우며 이미 보냈거나 확인 중인 기록과 다른 종류의 할 일은 보존합니다. 직접 실행을 막은 내부 함수는 기존 전용 판정/계좌 트리거만 부릅니다.0030을 더했고0029는 유지했습니다.
